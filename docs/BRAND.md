# 아올다 공식 로고 사용

요약: 공식 홈페이지의 로고·아이콘 원본을 사이트 헤더·푸터·홈·파비콘에 사용한다. 색·도형·비율을 보존하고 외부 요청 없이 제공하며 학습 본문과 기능은 별도로 유지한다.

## 원본과 적용

- `content/assets/aolda-logo.svg`: [공식 Logo.svg](https://www.aoldacloud.com/Logo.svg), 2026-10-16 확인. 헤더·푸터에서 사용하며 워드마크와 심벌의 원래 비율·그라디언트를 유지한다.
- `content/assets/aolda-icon.svg`: [공식 icon.svg](https://www.aoldacloud.com/icon.svg), 같은 날 홈페이지의 favicon 연결과 원본을 확인했다. 파비콘과 넓은 홈 화면의 장식 심벌로 사용한다.
- 사이트에서는 저장소에 포함된 파일을 상대 경로로 읽는다. 공식 자산을 다시 그리거나 색을 바꾸지 않는다. 이 문서는 원본에 대한 별도 재배포 라이선스를 부여하지 않는다.

## 표시와 접근성

헤더 로고는 학습 홈 링크이며 접근 가능한 이름은 ‘아올다 학습 홈’이다. 푸터에는 로고와 스터디 설명을 함께 둔다. 홈의 큰 심벌은 장식이므로 스크린 리더에서 제외하고 좁은 화면에서는 숨긴다. 기존 교재의 본문·모형·답안 동작은 변경하지 않는다.
