# 8주차 · 요청의 전체 흐름과 IPv6

요약: DNS→TCP→TLS→HTTP를 캐시·열린 연결 조건으로 설명하고 RTT 비용을 계산한다. 손실 하나의 전송 모형과 IPv4/IPv6를 비교한 뒤 기존 실습의 단일 장애를 각자 진단·복구한다.

<span id="weekly-study"></span>

## 개인 공부와 오프라인 확인

오프라인 모임 전까지 아래 범위를 공부하고 실습을 시도한다. 모임은 그 주의 학습을 마무리하는 자리로, 막힌 이유와 조건을 바꾼 결과를 설명하고 남은 보충을 정한다. [공동 질문](WORKSHEET.md)은 개인 공부의 출발점으로 쓰고, 모임에서는 근거를 비교한다. 별도 사전 모임이나 발표 자료는 필요하지 않다.

- **개념·문제:** DNS/TCP/TLS/HTTP의 캐시·연결별 비용, stop-and-wait/GBN/SR의 손실 시간축, IPv6 주소 범위·NDP. [교재](CONCEPTS.md) → [공식 지정 절](SOURCES.md) → [복습](REVIEW.md) 순서로 읽고, 먼저 답한 뒤 [해설](ANSWERS.md)과 비교한다.
- **실습·분석:** 주소/경로·IPv6 루프백 관찰 또는 제공 분석. C08 진단은 원인을 미리 보지 않고 오프라인에서 수행. 공개 교재 계산은 먼저 풀고 해설과 비교. [실행 안내](LINUX.md)의 필수/선택과 제공 분석/직접 수행 구분을 따른다.
- **모임에 가져올 것:** 본인의 근거에서 고른 출력·풀이와 아직 설명이 막힌 질문. 개인 학습 노트에 한 번 정리하고 원시 로그·pcap은 파일 링크로 연결해도 된다. 새 제출 양식은 만들지 않는다.

<span id="personal-notes"></span>

### 개인 공부를 정리할 때

기존 개인 학습 노트에 아래 세 가지를 중심으로 정리한다. 모임 전에는 현재 답과 막힌 지점을 남기고, 모임 뒤에는 확인한 차이와 보충할 부분을 고친다. 정해진 개수·분량이나 새 제출물은 없다.

- **주요 질문과 내 답:** [공동 질문](WORKSHEET.md)과 아래 확인 질문에 먼저 내 말로 답한다. 이유·성립 조건과 공식 자료·실습 근거를 연결하고, [분리 해설](ANSWERS.md)은 시도 뒤에 비교한다.
- **헷갈리는 개념 비교:** [핵심 설명](CONCEPTS.md)에서 DNS·HTTP 캐시와 열린 연결, ARP와 NDP의 역할·관찰 위치·성공 범위를 비교한다. 두 개념이 다른 결론을 내는 예를 들어 본다.
- **이번 주 꼭 기억하고 이해할 핵심 개념:** [핵심 정리](CONCEPTS.md)의 W08-K1~K3를 길잡이로 용어·역할·동작 순서를 추린다. 필요한 공식은 식·단위·성립 조건과 적용 이유를 함께 설명한다. 예제 주소·일회성 출력값을 외우는 목록으로 만들지 않는다.

실습 근거는 해당 질문·개념 아래에 예상·실제 관찰·수정한 이해와 함께 연결한다. 제공 분석과 직접 실행을 구별하고 관찰하지 않은 결과는 채우지 않는다. 입력 화면을 썼다면 이동 전에 답안을 내려받는다. [전체 개념 색인의 정리 방법](../CONCEPT_INDEX.md#personal-study)은 다른 주차에도 같은 방식으로 쓸 수 있다.

### 오프라인에서 확인할 질문

1. **중심 질문:** 두 번째 HTTPS에서 DNS·TCP·TLS·HTTP 중 무엇이 생략되는지 조건별로 설명할 수 있을까?
2. **조건을 바꾸면:** 열린 연결만 닫히거나 손실 번호가 1에서 3으로 바뀌면 비용·재전송 집합은?
3. **앞 개념을 다시 쓰면:** 3주 ARP와 IPv6 NDP, 루프백 관찰과 외부 연결의 차이는?

중심 질문을 먼저 설명하고 나머지는 짧은 후속 질문으로 사용한다. [분리 해설](ANSWERS.md)과 실제 근거를 대조하되 답을 본 시도와 독립 설명을 구별한다. 개인 공부에서 마친 정상 실습을 전부 반복하지 않고, 막힌 항목과 한 조건 변경·복구를 각자 확인한다.

## 필수와 선택

필수 이론은 전체 통신 그림과 RTT 계산, 제공 시간축에서 stop-and-wait·GBN·SR의 재전송 범위, IPv4/IPv6·ARP/NDP 비교다. 새 신뢰 전송 구현을 과제로 만들지 않는다. 필수 실습 A는 Linux 주소·경로 비교와 `::1` 관찰이며 IPv6 통신이 불가능하면 제공 trace 비교를 사용한다. B는 **정답을 숨긴 기존 단일 장애 하나를 각자 진단·재현·복구**한다. 환경이 막혀 분석만 했다면 직접 수행은 보충한다.

C08은 기존 복습·실습의 일부를 대체한다. 새 발표·고정 팀 기록·개인 마무리는 없다. 실제 명령·출력은 개인 파일에 한 번 보관한다. 해설을 본 뒤 따라 한 수행은 독립 진단과 구별한다. 한 명의 설명을 모두의 통과로 쓰지 않는다.

SLAAC·DHCPv6 상세, 실제 NDP 캡처와 IPv6 경로 구성은 선택이다. 외부 IPv6 연결·공용망 설정 변경·새 VM은 요구하지 않는다. 9주차 VLAN/STP/LACP, 10주차 OSPF, 14주차 윈도 성능 계산은 뒤에서 다룬다. [전체 개념 색인](../CONCEPT_INDEX.md)에서 W08-K1\~K3을 찾는다.
