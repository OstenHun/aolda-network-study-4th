# 12주차 · 연결 표시 너머의 경로와 경계

요약: 무선 연결·매체 접근·VPN 경로를 제공 자료로 분석하고 작은 망을 그린다. 신호·주소·경로·암호화·접근 정책의 역할을 구별하며 앞 주차의 직접 전환·복구 근거로 C12를 확인한다.

<span id="weekly-study"></span>

## 개인 공부와 오프라인 확인

오프라인 모임 전까지 아래 범위를 공부하고 실습을 시도한다. 모임은 그 주의 학습을 마무리하는 자리로, 막힌 이유와 조건을 바꾼 결과를 설명하고 남은 보충을 정한다. [공동 질문](WORKSHEET.md)은 개인 공부의 출발점으로 쓰고, 모임에서는 근거를 비교한다. 별도 사전 모임이나 발표 자료는 필요하지 않다.

- **개념·문제:** 무선 연결·SSID/BSSID·신호/채널, CSMA/CD·CSMA/CA·전이중, VLAN/서브넷 설계, VPN 경로·보호·정책. [교재](CONCEPTS.md) → [공식 지정 절](SOURCES.md) → [복습](REVIEW.md) 순서로 읽고, 먼저 답한 뒤 [해설](ANSWERS.md)과 비교한다.
- **실습·분석:** A 무선/매체 접근 자료, B VPN 전후 경로와 작은 망 구성도 분석. C12에는 앞 STP/LACP·OSPF·정책 직접 근거 준비. 새 VPN 설치는 필수가 아님. [실행 안내](LINUX.md)의 필수/선택과 제공 분석/직접 수행 구분을 따른다.
- **모임에 가져올 것:** 본인의 근거에서 고른 출력·풀이와 아직 설명이 막힌 질문. 개인 학습 노트에 한 번 정리하고 원시 로그·pcap은 파일 링크로 연결해도 된다. 새 제출 양식은 만들지 않는다.

<span id="personal-notes"></span>

### 개인 공부를 정리할 때

기존 개인 학습 노트에 아래 세 가지를 중심으로 정리한다. 모임 전에는 현재 답과 막힌 지점을 남기고, 모임 뒤에는 확인한 차이와 보충할 부분을 고친다. 정해진 개수·분량이나 새 제출물은 없다.

- **주요 질문과 내 답:** [공동 질문](WORKSHEET.md)과 아래 확인 질문에 먼저 내 말로 답한다. 이유·성립 조건과 공식 자료·실습 근거를 연결하고, [분리 해설](ANSWERS.md)은 시도 뒤에 비교한다.
- **헷갈리는 개념 비교:** [핵심 설명](CONCEPTS.md)에서 터널과 암호화, 오류 검출과 인증의 역할·관찰 위치·성공 범위를 비교한다. 두 개념이 다른 결론을 내는 예를 들어 본다.
- **이번 주 꼭 기억하고 이해할 핵심 개념:** [핵심 정리](CONCEPTS.md)의 W12-K1~K3를 길잡이로 용어·역할·동작 순서를 추린다. 필요한 공식은 식·단위·성립 조건과 적용 이유를 함께 설명한다. 예제 주소·일회성 출력값을 외우는 목록으로 만들지 않는다.

실습 근거는 해당 질문·개념 아래에 예상·실제 관찰·수정한 이해와 함께 연결한다. 제공 분석과 직접 실행을 구별하고 관찰하지 않은 결과는 채우지 않는다. 입력 화면을 썼다면 이동 전에 답안을 내려받는다. [전체 개념 색인의 정리 방법](../CONCEPT_INDEX.md#personal-study)은 다른 주차에도 같은 방식으로 쓸 수 있다.

### 오프라인에서 확인할 질문

1. **중심 질문:** Wi-Fi/VPN 연결 표시가 있는데 서버 요청이 실패하면 무엇이 아직 미확인인가?
2. **조건을 바꾸면:** 서버 경로 한 행과 접근 정책 한 항목 변경은 각각 어떤 관찰로 구별할까?
3. **앞 개념을 다시 쓰면:** 9~11주 VLAN·OSPF·NAT·정책은 작은 망에서 각각 어디에 있으며 한 장치 고장 시 무엇이 함께 멈추는가?

중심 질문을 먼저 설명하고 나머지는 짧은 후속 질문으로 사용한다. [분리 해설](ANSWERS.md)과 실제 근거를 대조하되 답을 본 시도와 독립 설명을 구별한다. 개인 공부에서 마친 정상 실습을 전부 반복하지 않고, 막힌 항목과 한 조건 변경·복구를 각자 확인한다.

### 같은 개념을 더 깊게 연결하기

앞 계층을 작은 망과 보호 경계로 묶는다. 13주 클라우드 자원과 캡슐화/크기 문제로 이어진다. [핵심 개념의 단계별 연결](../CONCEPT_INDEX.md#operations-progression)에서 앞뒤 학습을 찾는다.

## 이번 주의 질문

**Wi-Fi와 VPN이 모두 연결되어 있는데 왜 서버에는 닿지 않을까?** 연결 표시가 증명하는 구간부터 나눈다. [6주차 요청과 로그](../week-06/CONCEPTS.md), [7주차 왕복 경로](../week-07/CONCEPTS.md), [11주차 정책과 관찰 위치](../week-11/CONCEPTS.md)를 재사용한다.

## 함께 공부하는 순서

1. [중심 질문](WORKSHEET.md)을 읽고 필요한 관찰 두 가지를 고른다.
2. [개념 교재](CONCEPTS.md)와 [짧은 공식 지정 절](SOURCES.md)을 함께 찾는다. 한 사람이 연결·경로·정책을 나누어 설명한다.
3. 다른 사람이 신호·경로·정책 중 한 조건을 바꿔 묻는다. 설명자는 교대한다.
4. [제공 자료 실습](LINUX.md)에서 무선 상태와 매체 접근, VPN 전후 경로를 분석하고 유선·무선·게스트·서버망을 그린다.
5. [복습](REVIEW.md)을 먼저 풀고 [분리 해설](ANSWERS.md)과 비교한다. C12는 기존 활동 15~20분을 대체하며 앞 주차 본인 근거를 재사용한다.

## 필수와 선택

| 구분 | 할 일과 근거 |
| --- | --- |
| 필수 분석 A | 제공 무선 상태·요청/로그와 매체 접근 자료를 비교한다. CSMA/CD·CSMA/CA와 현대 전이중 링크를 구별한다 |
| 필수 분석 B·설계 | Linux 형식의 VPN 전후 경로에서 목적지별 전달 범위를 찾고 작은 망의 구성도·허용/차단 경로·고장 지점을 표시한다 |
| C12 | VLAN/STP/LACP·LS/DV·AS/BGP·OSPF·NAT/정책·CRC/무선 접근을 앞선 근거로 설명한다 |
| 선택 | 본인 무선 NIC의 조회, 이미 허가된 VPN의 전후 조회. 무선 모니터 모드·새 VPN 설치·학교 공유기 변경·VPN 독립 초기 구축은 요구하지 않는다 |

제공 파일은 **자체 교육용 가공 자료**다. 실제 무선 캡처·VPN 실측이 아니다. 제공 분석으로 이번 주 필수 분석을 수행할 수 있지만 9·10·11주차의 필수 직접 수행 누락을 대신하지 않는다. 상세 분석과 기존 본인 근거는 개인 파일에 한 번 보관한다.

[진행자 안내](FACILITATOR.md)는 개인 공부의 준비 범위와 한 번의 오프라인 확인 순서를 안내한다. 새 팀 기록·개인 마무리·발표 양식은 없다. 다음에는 같은 주소·경로·정책 질문을 클라우드 자원에 적용한다.
