# 12주차 진행자 · 연결 표시를 근거로 풀기

요약: 중심 질문 하나와 제공 무선·VPN 분석을 두 60분 모임에 배치한다. C12는 기존 15~20분을 대체하며 앞 주차 직접 수행 근거를 재사용한다. 막히면 선택 범위를 줄이고 필수 수행은 보충한다.

## 시작 전 준비

[학습 홈](README.md)·[핵심 3/혼동 2](CONCEPTS.md)·[공식 지정 절](SOURCES.md)과 실습의 네 파일을 열어 본다. 필수는 제공 분석·본인 구성도다. 무선 NIC·VPN 설치가 없어도 수행할 수 있다. 파일이 빠지거나 읽을 수 없으면 먼저 제공 경로를 복구한다. 없는 자료를 환경 제약이라고 넘기지 않는다.

9주차 본인 STP/LACP,10주차 OSPF 전환·복구,11주차 규칙 변경·복구 근거를 찾게 한다. 미수행이면 C12에서 분석 이해와 직접 수행 보충을 구별한다. 앞 주차 필수 실습을 새 표 분석으로 대체하지 않는다. 본인 상세 근거는 개인 파일 한 곳에 두며 새 팀 기록·개인 마무리·발표 양식을 만들지 않는다.

## 공동학습 60분의 추정 배치

| 시간 | 함께 할 일 |
| --- | --- |
| 0~5분 | 7주차 로컬 경로/왕복,11주차 LISTEN/정책/GET을 짧게 복습하고 [중심 질문](WORKSHEET.md)을 고른다 |
| 5~15분 | [필수 공식 세 지정 범위](SOURCES.md)를 나눠 읽는다. 연결 필드·보호/우회/폐기·대기/백오프를 찾는다 |
| 15~30분 | K1/K2와 A1/A2를 함께 공부한다. 신호와 요청 성공, 백오프 멈춤·재시도를 연결한다 |
| 30~45분 | 한 사람이 V1의 목적지별 경로·보호 경계를 설명하고 다른 사람은 V2 또는 V3 한 조건을 바꿔 묻는다 |
| 45~55분 | K3와 작은 망 입력을 읽고 장치·VLAN·게이트웨이·정책 위치를 놓는다 |
| 55~60분 | 남은 질문과 기존 C12 근거 위치를 확인한다. 다음 설명자를 교대한다 |

읽기 시간은 추정이며 영문 해독에 막히면 해당 단어를 짧게 풀고 교재의 같은 근거로 돌아간다. 공식 문서 전체를 숙제로 추가하지 않는다.

## 실습 60분의 추정 배치

| 시간 | 각자 할 일 |
| --- | --- |
| 0~5분 | 고정 대상·가공 자료 조건과 비교할 한 입력을 확인한다 |
| 5~20분 | A1/A2의 무선/매체 분석과 조건 복원을 각자 설명한다 |
| 20~35분 | B1의 VPN 전후/정책/경로 비교와 B2 본인 작은 망 구성도를 확인한다 |
| 35~55분 | [C12](LINUX.md#c12)로 기존 활동을 대체한다. 이전 직접 수행 근거·LS/DV 작은 계산·역할 구별·이번 무선/보호 경계를 확인한다 |
| 55~60분 | 빠진 연결·오답을 고치고 개인 근거를 보관한다. 미수행 항목의 보충 행동만 정한다 |

설치·선택 직접 조회는 이 시간 밖이다. 넘치면 선택 보조 질문·새 VPN 구성·추가 측정을 줄이고 필수 분석이나 앞 주차 직접 수행을 보충한다. 한 사람의 설명을 전원의 독립 확인으로 쓰지 않는다.

## 막힐 때 제공할 짧은 설명

- **연결 표시가 전부라고 할 때:** 단말·GW·서버 세 칸을 놓고 C의 DROP과 LISTEN/GET을 각각 올려놓게 한다.
- **슬롯을 계속 줄일 때:** M1에서 A가 송신하는 동안 B의 숫자를 고정한 뒤 다시 유휴 간격을 지난 위치에서 센다. 실제 시간값을 새로 계산하지 않는다.
- **VPN이면 모두 암호화라고 할 때:** V1의 서버/외부 서비스 두 목적지 경로와 GW 복호화 지점에 서로 다른 선을 그린다. 경로표와 보호 설정의 근거도 나눈다.
- **SSID만으로 격리됐다고 할 때:** 같은 AP 업링크의 VLAN 매핑과 GW 차단 위치를 찾게 한다. 같은 VLAN 단말 격리는 별도 질문이다.
- **C12 근거가 없을 때:** 설명·제공 분석은 확인한 만큼만 남기고 앞 주차 준비된 구성의 직접 전환·복구를 보충한다. 숫자 정답으로 수행 결손을 상쇄하지 않는다.

## 확인과 다음 연결

[분리 해설](ANSWERS.md)은 필수 요소·흔한 오답·가정의 한계를 제공한다. 자체 문항이며 기업 기출로 소개하지 않는다. 다음 주에는 본인 허가 클라우드에서 주소·경로·정책을 실제 자원과 대조할 준비를 한다. 이번 제공 분석을 실제 클라우드 운영이나 O01~O05 수행으로 표시하지 않는다.
