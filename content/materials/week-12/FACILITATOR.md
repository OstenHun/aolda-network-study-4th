# 12주차 진행자 · 연결 표시를 근거로 풀기

요약: 개인 공부에서 개념·문제·실습을 준비하고 오프라인 한 번에서 설명·조건 변경·직접 수행을 확인한다. 준비·복구와 제공 분석의 경계를 지키며 막힌 필수 항목을 보충한다.

## 시작 전 준비

[학습 홈](README.md)·[핵심 3/혼동 2](CONCEPTS.md)·[공식 지정 절](SOURCES.md)과 실습의 네 파일을 열어 본다. 필수는 제공 분석·본인 구성도다. 무선 NIC·VPN 설치가 없어도 수행할 수 있다. 파일이 빠지거나 읽을 수 없으면 먼저 제공 경로를 복구한다. 없는 자료를 환경 제약이라고 넘기지 않는다.

9주차 본인 STP/LACP,10주차 OSPF 전환·복구,11주차 규칙 변경·복구 근거를 찾게 한다. 미수행이면 C12에서 분석 이해와 직접 수행 보충을 구별한다. 앞 주차 필수 실습을 새 표 분석으로 대체하지 않는다. 본인 상세 근거는 개인 파일 한 곳에 두며 새 팀 기록·개인 마무리·발표 양식을 만들지 않는다.

## 한 주의 개인 공부와 오프라인 확인

개인 준비는 [학습 홈의 정리 안내](README.md#personal-notes)에 따라 주요 질문과 내 답·헷갈리는 개념 비교·꼭 기억하고 이해할 핵심을 살핀다. 노트 분량을 평가하지 않고 이유·조건 변경·관련 실습 근거로 확인한다. 모임 뒤에는 틀린 설명과 남은 보충만 기존 개인 노트에서 고치며 중복 제출을 요구하지 않는다.

[학습 홈의 개인 공부 범위와 세 확인 질문](README.md#weekly-study)을 오프라인 모임 전까지 준비한다. 모임은 그 주 학습을 마무리하고 남은 보충을 정하는 자리다. 개념·공식 지정 절·복습과 준비된 실습의 정상→변경→복구는 개인 공부에서 시도한다. 모임 전 완성 답안·발표 자료를 요구하지 않으며 막힌 질문과 본인 근거를 가져오게 한다. 진단 원인을 가리는 과제는 정상 기준과 도구까지만 준비한다.

오프라인은 한 번의 모임에서 **설명 → 새 조건 → 본인 실습/분석 확인 → 보충 결정**으로 진행한다. 아래 60분은 시간 배분 예시이며 모임 길이나 추가 회차를 확정하는 표가 아니다.

| 시간 예시 | 진행자가 확인할 것 |
| --- | --- |
| 0~10분 | 개인 공부에서 막힌 질문과 2~4학습 단위 전 개념 하나를 골라 근거로 설명 |
| 10~25분 | 학습 홈의 중심 질문 → 조건 변경. 각자 시도한 근거·막힌 이유 비교 |
| 25~50분 | A 무선/매체 접근 자료, B VPN 전후 경로와 작은 망 구성도 분석. 이미 수행했다면 근거를 보고 다른 한 조건의 판단·변경·복구 확인 |
| 50~60분 | 정상 복구·받은 도움·미완료 구분, 개인 학습 노트에 필요한 보충과 다음 질문 연결 |

개인 학습 시간을 고정된 2~3시간으로 제한하지 않는다. 필수 범위를 먼저 공부하고 실제 막힘에 따라 시간을 배분한다. 주차를 미리 분할하거나 필수 기준을 낮추지 않으며, 개인 공부 후에도 해결되지 않는 항목만 보충한다. C04/C08/C12/C16은 해당 주 기존 설명·실습을 대체하고 점검을 별도로 더하지 않는다. 한 사람의 답·팀 합의·파일 제출은 개인 이해/직접 수행의 증거가 아니다.

## 막힐 때 제공할 짧은 설명

- **연결 표시가 전부라고 할 때:** 단말·GW·서버 세 칸을 놓고 C의 DROP과 LISTEN/GET을 각각 올려놓게 한다.
- **슬롯을 계속 줄일 때:** M1에서 A가 송신하는 동안 B의 숫자를 고정한 뒤 다시 유휴 간격을 지난 위치에서 센다. 실제 시간값을 새로 계산하지 않는다.
- **VPN이면 모두 암호화라고 할 때:** V1의 서버/외부 서비스 두 목적지 경로와 GW 복호화 지점에 서로 다른 선을 그린다. 경로표와 보호 설정의 근거도 나눈다.
- **SSID만으로 격리됐다고 할 때:** 같은 AP 업링크의 VLAN 매핑과 GW 차단 위치를 찾게 한다. 같은 VLAN 단말 격리는 별도 질문이다.
- **C12 근거가 없을 때:** 설명·제공 분석은 확인한 만큼만 남기고 앞 주차 준비된 구성의 직접 전환·복구를 보충한다. 숫자 정답으로 수행 결손을 상쇄하지 않는다.

## 확인과 다음 연결

[분리 해설](ANSWERS.md)은 필수 요소·흔한 오답·가정의 한계를 제공한다. 자체 문항이며 기업 기출로 소개하지 않는다. 다음 주에는 본인 허가 클라우드에서 주소·경로·정책을 실제 자원과 대조할 준비를 한다. 이번 제공 분석을 실제 클라우드 운영이나 O01~O05 수행으로 표시하지 않는다.
