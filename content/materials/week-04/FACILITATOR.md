# 4주차 · 진행자 안내

요약: 개인 공부에서 개념·문제·실습을 준비하고 오프라인 한 번에서 설명·조건 변경·직접 수행을 확인한다. 준비·복구와 제공 분석의 경계를 지키며 막힌 필수 항목을 보충한다.

## 질문과 준비

[학습 홈](README.md) → [공동 질문](WORKSHEET.md) → [교재](CONCEPTS.md) → [실습](LINUX.md) → [복습](REVIEW.md)·[분리 해설](ANSWERS.md)을 연결한다. [전체 개념 색인](../CONCEPT_INDEX.md)에서 W04-K1~K3를 다시 찾는다. 이전 주차 자료가 있어도 숙달을 전제하지 않는다.

기존 VM·SSH 셸 두 개·Python 3·파일 전달을 먼저 확인한다. Linux 조회용 `ss`, 선택 캡처용 `tcpdump`와 권한을 확인한다. 파일은 실습 페이지에서 내려받는다. 추가 VM·방화벽 변경·netem 설치는 필요하지 않다. 루프백 예제는 외부 클라우드 연결 검증을 대신하지 않는다.

## 한 주의 개인 공부와 오프라인 확인

개인 준비는 [학습 홈의 정리 안내](README.md#personal-notes)에 따라 주요 질문과 내 답·헷갈리는 개념 비교·꼭 기억하고 이해할 핵심을 살핀다. 노트 분량을 평가하지 않고 이유·조건 변경·관련 실습 근거로 확인한다. 모임 뒤에는 틀린 설명과 남은 보충만 기존 개인 노트에서 고치며 중복 제출을 요구하지 않는다.

[학습 홈의 개인 공부 범위와 세 확인 질문](README.md#weekly-study)을 오프라인 모임 전까지 준비한다. 모임은 그 주 학습을 마무리하고 남은 보충을 정하는 자리다. 개념·공식 지정 절·복습과 준비된 실습의 정상→변경→복구는 개인 공부에서 시도한다. 모임 전 완성 답안·발표 자료를 요구하지 않으며 막힌 질문과 본인 근거를 가져오게 한다. 진단 원인을 가리는 과제는 정상 기준과 도구까지만 준비한다.

오프라인은 한 번의 모임에서 **설명 → 새 조건 → 본인 실습/분석 확인 → 보충 결정**으로 진행한다. 아래 60분은 시간 배분 예시이며 모임 길이나 추가 회차를 확정하는 표가 아니다.

| 시간 예시 | 진행자가 확인할 것 |
| --- | --- |
| 0~10분 | 개인 공부에서 막힌 질문과 2~4학습 단위 전 개념 하나를 골라 근거로 설명 |
| 10~25분 | 학습 홈의 중심 질문 → 조건 변경. 각자 시도한 근거·막힌 이유 비교 |
| 25~50분 | TCP/UDP 송수신 비교와 포트 한 조건 변경→복구. 이미 수행했다면 근거를 보고 다른 한 조건의 판단·변경·복구 확인 |
| 50~60분 | 정상 복구·받은 도움·미완료 구분, 개인 학습 노트에 필요한 보충과 다음 질문 연결 |

개인 학습 시간을 고정된 2~3시간으로 제한하지 않는다. 필수 범위를 먼저 공부하고 실제 막힘에 따라 시간을 배분한다. 주차를 미리 분할하거나 필수 기준을 낮추지 않으며, 개인 공부 후에도 해결되지 않는 항목만 보충한다. C04/C08/C12/C16은 해당 주 기존 설명·실습을 대체하고 점검을 별도로 더하지 않는다. 한 사람의 답·팀 합의·파일 제출은 개인 이해/직접 수행의 증거가 아니다.

검색이 막히면 [출처 지정 절](SOURCES.md)을 바로 제시한다. 스트림이 어렵다면 `recv(3)`이 최대 세 바이트라는 점과 개행 종료 조건만 먼저 읽는다. GBN/SR·혼잡 알고리즘·대규모 부하 실험은 이후 주차로 둔다.

C04는 기존 실험/복습 일부를 대체한다. 200·404·연결 실패의 이전 근거를 사용할 수 있지만 ACK와 앱 성공을 구별하는 추가 질문을 한다. 본인이 조건을 바꾸고 복구하지 않았다면 보충할 실습으로 남긴다. 평가할 때는 각자의 설명과 실제 실습 결과를 함께 확인한다.

## 환경이 막히거나 시간이 부족할 때

5분 이상 환경 해결에 머물면 교재의 가상 시간축·코드로 분석을 계속하고 직접 실행을 미완료로 남긴다. 선택 패킷 캡처·RTT 보조 질문을 먼저 줄인다. TCP/UDP 예제 직접 실행과 포트 변경/복구는 다음 보충에서 확보한다. 관찰된 TCP 청크 개수·UDP 오류 종류가 예시와 달라도 실제 조건을 읽으며 고정된 결과를 강요하지 않는다.

## 다음 복습으로 연결

다음 주 첫 5분에 서버 포트가 같은 두 연결과 ACK 의미를 다시 묻는다. 개인별 설명·직접 수행·제공 분석을 구분하며 팀의 합의나 해설 확인을 개인 통과로 기록하지 않는다. 상세 근거는 개인 파일에 한 번 보관한다.
