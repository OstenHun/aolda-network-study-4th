# 내 VM 접속 기록

요약: 본인 VM의 설정·접속 결과와 성공한 이유를 기록한다. 오류 없이 완료할 수 있으며 실패했을 때만 진단 칸을 사용한다. 직접 생성·기존 설정 확인·제공 증거 분석을 구분한다.

## 사용하는 방법

[교재](LESSON.md)를 읽으며 내 설정과 실행 결과를 남긴다. 먼저 생각한 답이 있으면 적고, 확인한 뒤에는 어떤 출력 때문에 그렇게 설명할 수 있는지 덧붙인다. 처음에 답을 모르겠다면 설정을 확인한 뒤 돌아와도 된다. [해설](FACILITATOR.md#answers)은 먼저 답한 뒤 읽는다.

- 이름과 팀: 미작성
- 실제 날짜·시각·장소: 미작성
- 수행 방식: 미작성

직접 생성, 기존 자원 확인, 시연 관찰, 제공 자료 분석 중 실제로 한 활동을 적는다.

## 접속한 뒤 남길 것

- PC에서 실행한 SSH 명령: 미실시
- 서버 호스트 키 대조·사용자 인증 결과(비밀정보 제외): 미확인
- 원격 `hostname`, `whoami`, `pwd` 결과: 미실시
- 두 번째 셸·server.py 원격 위치: 미확인
- 내 설정으로 그린 경로: 미작성
- 이 경로에서 VPN·라우터·Floating IP·보안 그룹·SSH 서버가 각각 한 일: 미작성

그림에는 출발지(src)와 목적지(dst), TCP 포트를 붙인다. 실제 캡처하지 않은 VM 수신 src나 임시 포트는 미관찰로 남긴다. 정상 접속을 위해 모든 중간 지점의 패킷을 캡처할 필요는 없다.

2. 같은 VM에 창을 두 개 열면 호스트가 두 대가 되는가? 각 셸의 현재 폴더는 항상 같은가?
3. TCP 22 로그인이 됐으니 모든 포트도 접근 가능하다고 할 수 있는가?
