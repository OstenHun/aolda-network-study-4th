여기서 시작하기

내 VM을 준비하고, 내 PC에서 접속한 뒤 왜 연결되는지 설명한다. 처음부터 접속이 잘돼도 좋다. 각 설정이 어떤 일을 했는지 설명한 뒤 HTTP 실습으로 넘어간다.

본인에게 허용된 계정과 인증 방식을 사용한다. 교재 S7의 ssh <본인_계정>@<본인_Floating_IP>로 로그인한다. 서버 지문 확인과 사용자 인증은 서로 다른 단계다.

브라우저로 읽을 때는 SSH 학습 홈을 연다. 교재를 읽으면서 내 기록에 답을 적고 Markdown으로 내려받을 수 있다. 기록은 자동 저장되지 않는다.

  1. 기본 교재: 프로젝트 → 망·라우터 → VM → Floating IP·VPN → 접근 규칙 → SSH 로그인.
  2. 질문·기록지: 본인의 설정·실제 결과·성공한 이유를 기록한다.
  3. 진행자 안내·해설: 준비 상태에 맞춰 시간을 조정한다.
  4. 접속 준비가 끝나면 기존 Linux HTTP 실습·1주차 학습 홈으로 간다.
  5. 접속이 막히면 교재 S7의 증상표를 확인한다. 오류를 일부러 재현하지 않는다.

이번에 익힐 것과 다음에 더 볼 것

필수는 각 설정의 역할, 본인의 주소·경로, SSH 연결과 신뢰·인증의 구분, 성공한 접속의 설명이다. /24·/32와 Floating IP의 주소 연결은 필요한 만큼 짚는다. SNAT 패킷 분석과 장애 재현은 기본 완료 조건이 아니다.

CIDR 계산은 2주차, TCP 상세는 4주차, SSH 원리는 6주차, 라우팅은 7주차, NAT·방화벽은 11주차, VPN은 12주차, 클라우드는 13주차로 이어간다. 전체 순서는 16주 커리큘럼에서 확인한다.

어디까지 했는지 남기기

  • 준비·접속: 본인에게 허용된 VM의 설정과 SSH 로그인 후 대상·계정 확인 결과를 남긴다. 이미 만들어진 자원을 확인했다면 직접 생성과 구분한다.
  • 이해: 자기 주소로 경로를 그리고 설정의 역할을 설명한다. 오류 없이 성공해도 충족할 수 있다.
  • HTTP: 개인 실습 기록에 네 상태·패킷 분석·독립 재현을 남기고 원본 출력·pcap은 별도 보관한다. 팀 활동에는 질문·근거 위치·바뀐 설명을 남긴다.

환경이 준비되지 않았다면 제공 자료를 분석하고, 본인 생성·접속·직접 실행은 구분해 기록한다.

설정과 기록을 찾아볼 때

예제의 주소를 실제 접속에 사용하지 않는다. 출처에서 개념의 근거를 확인하고 본인 환경의 결과와 구분한다.
