사용하는 방법

교재를 읽으며 내 설정과 실행 결과를 남긴다. 먼저 생각한 답이 있으면 적고, 확인한 뒤에는 어떤 출력 때문에 그렇게 설명할 수 있는지 덧붙인다. 처음에 답을 모르겠다면 설정을 확인한 뒤 돌아와도 된다. 해설은 먼저 답한 뒤 읽는다.

직접 생성, 기존 자원 확인, 시연 관찰, 제공 자료 분석 중 실제로 한 활동을 적는다.

접속한 뒤 남길 것

그림에는 출발지(src)와 목적지(dst), TCP 포트를 붙인다. 실제 캡처하지 않은 VM 수신 src나 임시 포트는 미관찰로 남긴다. 정상 접속을 위해 모든 중간 지점의 패킷을 캡처할 필요는 없다.

짝에게 설명해 보기

  1. 접속할 VM이 바뀌면 주소·계정·호스트 키 중 무엇을 다시 확인해야 할까?
  2. 같은 VM에 창을 두 개 열면 호스트가 두 대가 되는가? 각 셸의 현재 폴더는 항상 같은가?
  3. TCP 22 로그인이 됐으니 모든 포트도 접근 가능하다고 할 수 있는가?
  4. PC에서 실행한 curl과 원격 Linux에서 실행한 curl의 127.0.0.1은 같은 곳인가?

오류가 있을 때만 작성

성공했다면 해당 없음으로 남긴다. 교재의 증상표와 선택 NAT 해설은 필요한 경우에만 읽는다. 사례 분석을 본인 장애 해결로 기록하지 않는다.
