# 2주차 복습 문제

요약: IPv4 주소의 역할, /24·/26 범위, 게이트웨이와 도달성 판단을 점검하는 자체 작성 8문항이다. 먼저 풀고 별도 해설에서 계산과 판단 근거를 확인한다.

## 풀기 전에

이 복습은 공동 탐구·P1/P2 뒤 개인 시간에 푼다. 중심 질문 외에 여덟 문제를 모임에서 모두 발표하지 않는다. 모든 주소와 명령 출력은 **문제용 가상 사례**다. 아올다 VM의 실제 설정이나 실측 결과로 기록하지 않는다. `192.0.2.0/24`는 [IANA가 문서 예시용으로 예약한 범위](https://www.iana.org/assignments/iana-ipv4-special-registry/iana-ipv4-special-registry.xhtml)다. 문항마다 **답 + 계산 또는 출력 근거 한 문장**을 적는다. [해설](ANSWERS.md)은 풀이 후에 연다.

## 기본 문항

### Q1. 주소와 포트 구별

VM 안의 `curl`이 `127.0.0.1:8080` 서버에 요청했다. `127.0.0.1`과 `8080`은 각각 무엇을 식별하는가? 개인 PC에서 같은 문자열로 요청하면 같은 VM 서버를 가리키는가?

### Q2. /24의 범위

가상의 인터페이스가 `192.0.2.10/24`일 때 서브넷 마스크, 네트워크 주소, 브로드캐스트 주소, 일반적인 호스트 주소 범위를 쓰고 `192.0.2.70`이 이 범위에 속하는지 판단하라.

### Q3. /26의 네 구간

`192.0.2.0/24`를 크기가 같은 `/26` 네 구간으로 나누었다. 네 네트워크 주소를 적고, `192.0.2.70/26`이 속한 구간의 브로드캐스트와 일반적인 사용 가능 호스트 범위를 계산하라.

### Q4. 마스크 하나만 변경

주소 A=`192.0.2.10`, B=`192.0.2.70`이다. 둘 다 `/24`일 때와 A만 `/26`으로 바뀌었을 때, **A의 관점에서** B를 같은 서브넷으로 판단하는지 각각 쓰라. A에는 해당 인터페이스의 직접 연결 경로 외에 다른 경로가 없다고 가정한다. 두 번째 경우 A가 B를 향한 경로를 고를 수 있는가? B 쪽 설정은 그대로 `/24`다.

### Q5. 주소 용도 분류

다음 주소를 RFC 1918 사설, 루프백, 문서 예시용, 그 밖의 주소로 분류하라: `10.1.2.3`, `172.31.255.1`, `172.32.0.1`, `192.168.2.9`, `127.0.0.1`, `192.0.2.10`. “RFC 1918 사설이 아님”만으로 실제 인터넷 도달을 보장할 수 있는가?

### Q6. 기본 게이트웨이 찾기

아래는 가상 출력이다. 인터페이스 주소·접두사, 직접 연결 경로, 기본 게이트웨이를 찾아 적어라. `10.24.8.70`은 로컬 주소의 `/24` 안에 있는가? 그 주소로 향하는 경로를 **계산상** 어디서 먼저 찾는가?

```text
ip -4 addr show dev eth0: inet 10.24.8.21/24 brd 10.24.8.255
ip -4 route: 10.24.8.0/24 dev eth0 scope link
ip -4 route: default via 10.24.8.1 dev eth0
```

### Q7. 계산과 통신 결과

두 VM의 주소가 `10.24.8.21/24`와 `10.24.8.70/24`로 보인다. “같은 서브넷이므로 ping은 반드시 성공한다”는 말에서 확정할 수 있는 부분과 확인이 더 필요한 부분을 나누어 적어라. 허용된 환경에서 볼 증거 두 가지를 제안하라.

### Q8. 경계값 진단

`10.24.8.70/26`의 네트워크·브로드캐스트·일반적인 첫/마지막 사용 가능 주소를 계산하라. `10.24.8.64`와 `10.24.8.127`을 일반 호스트 주소로 쓰겠다는 계획의 문제를 설명하라.

## 마무리

[실제 공개 시험 문항과 CCNA 연계 연습](CCNA_PRACTICE.md)은 선택이다. 원문이 답을 포함하는 경우도 있으므로 먼저 자신의 계산을 남긴다. 계산 정답만으로 실습 완료를 표시하지 않는다. 실제 `ip addr`·`ip route` 출력과, 수행했다면 관찰한 통신 결과는 개인 파일에 한 번 보관하고 [공동 질문](WORKSHEET.md)에 답할 때 필요한 부분을 보여 준다.
