2주차 진행자 안내 — 질문에서 기존 VM 실습으로

중심 질문 하나를 공동 검색·공부·한 명 설명·조건 변경으로 다루고 기존 VM의 P1 조회·P2 계산/검산으로 확인한다. 공식 자료와 계산·조회 결과를 연결해 설명을 확인하며 격리 마스크 변경은 선택으로 다룬다.

이번 주 목표

중심 질문은 “IP가 비슷한 두 VM은 같은 망으로 바로 통신할 수 있을까?”다. CIDR과 비트로 주소 범위를 계산하고 자기 VM의 주소·경로를 읽는다. 설명을 확인할 때는 이유를 묻고, 접두사를 바꾼 뒤 무엇을 더 확인해야 할지 묻는다.

공동 질문 → 공식 자료 찾기·핵심 개념 → P1·P2 → 자기 설명 → 분리 해설로 연결한다. 핵심 3개·혼동 2개·개발 사례 1개는 이 흐름 안에서 재사용한다. 답이 막히면 해당 교재 절로 돌아가며 별도 발표·필수 문항을 더하지 않는다.

시작 전 준비

둘 또는 셋이 함께 자료를 읽고 설명·근거 확인 역할을 나눈다. 설명자는 질문이나 회차마다 바꾼다. 아래 시간표는 각 60분으로 진행할 때의 예시이며 이해와 실습 속도에 맞춰 조정한다.

  • 기존 승인 VM의 접속·ip·python3·검산기 파일 위치를 확인한다. 새 VM/서버 구축을 요구하지 않는다.
  • 조회할 인터페이스와 허용 목적지를 정한다. 실제 이름·주소·기본 경로 유무는 출력으로 확인한다.
  • Linux에서 P1 조회와 P2 검산을 사전 재현하고 실제 환경·결과·미확인 범위를 보관한다. 기존 SSH 성공만으로 이번 명령 실행을 완료로 보지 않는다.
  • AWS CIDR의 지정 절과 ip-route의 get 설명을 열어 본다. 접근이 막히면 자체 교재/저장된 예제를 제시한다.
  • C1/C2 카드와 답이 분리된 해설, 다른 접두사/상대 주소의 작은 후속 카드 하나를 준비한다.
  • 공개 공유본에서 가릴 주소·이름을 안내하고 비밀번호/토큰을 기록하지 않게 한다.
  • 선택 데모는 별도로 권한·격리·정상/변경/복구·정리를 검증한 경우에만 안내한다.

사전 공동학습 60분 — 같이 찾아 답하기

시간 진행 확인할 것
0~5분 중심 질문과 C1/C2 조건 확인. 필요하면 1주차 실행 위치만 짧게 복습 무엇을 알고/모르는지
5~25분 지정 공식 자료 두 곳을 함께 탐색·공부하고 핵심 개념/그림을 읽기 접두사 범위와 경로 조회의 역할
25~40분 한 명이 근거로 답을 설명. 다른 사람이 A만 /26 등 조건을 바꿔 확인 원리·이유·양쪽 판단·미확인 부분
40~55분 자기 VM에서 확인할 줄·허용 목적지·파일/도구를 점검하고 실습 결과 예상 P1/P2 준비, 막히면 사용할 예제
55~60분 남은 질문을 확인하고 다음 실습 준비 다음 확인과 필요한 환경

설명자는 다음 질문/회차에서 교대한다. 전원이 매 질문마다 발표하지 않는다. 검색에 막히면 진행자가 지정 절을 바로 열고 작은 개념 설명을 제공한다. 자료를 찾은 양보다 중심 질문에 이유·근거를 붙여 답할 수 있는지를 본다. 원문의 필요한 절은 공동 탐구 시간에 함께 읽는다.

오프라인 60분 — P1·P2와 개인 확인

시간 활동 완료 근거·전환 기준
0~5분 중심 질문의 임시 답·실습 조건과 기존 VM 확인 실행 위치·허용 목적지
5~20분 P1: 각자 주소·경로·루프백/허용 목적지의 경로 조회 본인 명령·출력·dev/via/src·없는 값/오류. 접속 문제 5분 초과 시 예제 분석으로 전환하고 본인 조회 보충
20~38분 P2: C1/C2 손계산 뒤 Python 검산 양쪽 범위·방향별 포함 여부·검산 차이 수정
38~50분 종이/검산기 입력의 조건 하나를 바꾸어 독립 계산. 소그룹에서 1~2분 설명/출력 읽기 각자의 조건 변경·이유·다음 관찰. 호스트 설정은 바꾸지 않음
50~55분 필요한 분리 해설과 비교하고 바뀐 설명 확인 해설 확인과 독립 설명 구별
55~60분 실습 정리·필요한 파일 보관·보충 항목 확인 다음에 확인할 조건

두 실험을 진행하고 각자의 이해를 확인하는 것이 필수다. 계산이나 조회에 시간이 더 걸리면 보조 질문·시험 연계·선택 데모를 줄인다. 환경 때문에 제공 자료로 공부했다면 개념 확인과 본인 실행 미완료를 나눈다. 긴 전체 발표를 추가해 실습을 밀어내지 않는다.

선택 데모와 완료 판정

격리 마스크 변경은 필수 과제가 아니다. 선택 실험을 하지 않았다는 이유로 필수 실습을 미완료로 기록하지 않는다. 실행을 선택한 경우 Linux 안내의 격리 네임스페이스/veth에서 C1→A만 /26→C1 복구와 자원 정리를 확인한다. 기본 시연의 조회/요청 방향은 A→B이며 B→A를 실측했다고 쓰지 않는다. 실제 관찰하지 못한 동작은 예상/제공 분석으로 구분한다.

항목 독립 확인의 기준 보충이 필요한 경우
개념/추론 주소·접두사·경로·응답을 구별하고 C1/C2 양쪽 범위와 그 이유를 설명 숫자만 맞힘, 같은 범위=통신 성공으로 단정
P1 직접 수행 자기 VM 출력에서 실제 값·선택 경로와 관찰 범위를 읽음 접속/도구 미준비, 짝/제공 출력만 봄
P2 직접 수행 손계산·검산과 바뀐 조건 하나를 독립 확인 본인 검산/조건 변경 미실시
설명/다음에 확인할 것 소그룹 후속 질문에 현재 근거와 더 볼 것을 답함 발표자 답을 읽기만 함, 조회를 실제 응답으로 표시

한 명의 설명이나 실습 성공으로 다른 사람의 이해·직접 수행을 대신하지 않는다. 이번 실습으로 확인하는 것은 주소·경로·계산이다. 정책·NAT·서비스 정상 여부는 별도 관찰이 필요하다. 다음 회차에는 선택 분량을 줄여 막힌 필수 항목을 보충한다.
