# 2주차 진행자 안내 — 질문에서 기존 VM 실습으로

요약: 개인 공부에서 개념·문제·실습을 준비하고 오프라인 한 번에서 설명·조건 변경·직접 수행을 확인한다. 준비·복구와 제공 분석의 경계를 지키며 막힌 필수 항목을 보충한다.

## 이번 주 목표

중심 질문은 “IP가 비슷한 두 VM은 같은 망으로 바로 통신할 수 있을까?”다. CIDR과 비트로 주소 범위를 계산하고 자기 VM의 주소·경로를 읽는다. 설명을 확인할 때는 이유를 묻고, 접두사를 바꾼 뒤 무엇을 더 확인해야 할지 묻는다.

[공동 질문](WORKSHEET.md) → [공식 자료 찾기](ARTICLE_LESSON.md)·[핵심 개념](ESSENTIALS.md) → [P1·P2](../../labs/week-02/LINUX.md) → 자기 설명 → [분리 해설](ANSWERS.md#공동-질문-해설)로 연결한다. 핵심 3개·혼동 2개·개발 사례 1개는 이 흐름 안에서 재사용한다. 답이 막히면 해당 교재 절로 돌아가며 별도 발표·필수 문항을 더하지 않는다.

## 시작 전 준비

개인 공부에서 자료를 먼저 읽고 오프라인 소그룹에서 설명·근거 확인 역할을 교대한다. 실제 개인 공부와 막힌 지점을 기준으로 모임을 준비한다.

- [ ] 기존 승인 VM의 접속·`ip`·`python3`·검산기 파일 위치를 확인한다. 새 VM/서버 구축을 요구하지 않는다.
- [ ] 조회할 인터페이스와 허용 목적지를 정한다. 실제 이름·주소·기본 경로 유무는 출력으로 확인한다.
- [ ] Linux에서 P1 조회와 P2 검산을 사전 재현하고 실제 환경·결과·미확인 범위를 보관한다. 기존 SSH 성공만으로 이번 명령 실행을 완료로 보지 않는다.
- [ ] AWS CIDR의 지정 절과 ip-route의 `get` 설명을 열어 본다. 접근이 막히면 자체 교재/저장된 예제를 제시한다.
- [ ] C1/C2 카드와 답이 분리된 해설, 다른 접두사/상대 주소의 작은 후속 카드 하나를 준비한다.
- [ ] 공개 공유본에서 가릴 주소·이름을 안내하고 비밀번호/토큰을 기록하지 않게 한다.
- [ ] 선택 데모는 별도로 권한·격리·정상/변경/복구·정리를 검증한 경우에만 안내한다.

## 한 주의 개인 공부와 오프라인 확인

개인 준비는 [학습 홈의 정리 안내](README.md#personal-notes)에 따라 주요 질문과 내 답·헷갈리는 개념 비교·꼭 기억하고 이해할 핵심을 살핀다. 노트 분량을 평가하지 않고 이유·조건 변경·관련 실습 근거로 확인한다. 모임 뒤에는 틀린 설명과 남은 보충만 기존 개인 노트에서 고치며 중복 제출을 요구하지 않는다.

[학습 홈의 개인 공부 범위와 세 확인 질문](README.md#weekly-study)을 오프라인 모임 전까지 준비한다. 모임은 그 주 학습을 마무리하고 남은 보충을 정하는 자리다. 개념·공식 지정 절·복습과 준비된 실습의 정상→변경→복구는 개인 공부에서 시도한다. 모임 전 완성 답안·발표 자료를 요구하지 않으며 막힌 질문과 본인 근거를 가져오게 한다. 진단 원인을 가리는 과제는 정상 기준과 도구까지만 준비한다.

오프라인은 한 번의 모임에서 **설명 → 새 조건 → 본인 실습/분석 확인 → 보충 결정**으로 진행한다. 아래 60분은 시간 배분 예시이며 모임 길이나 추가 회차를 확정하는 표가 아니다.

| 시간 예시 | 진행자가 확인할 것 |
| --- | --- |
| 0~10분 | 개인 공부에서 막힌 질문과 2~4학습 단위 전 개념 하나를 골라 근거로 설명 |
| 10~25분 | 학습 홈의 중심 질문 → 조건 변경. 소그룹에서 설명자/확인자 교대 |
| 25~50분 | P1 자기 VM 주소·두 목적지 경로 조회, P2 C1/C2 손계산→Python 검산→카드 조건 하나 변경. 이미 수행했다면 근거를 보고 다른 한 조건의 판단·변경·복구 확인 |
| 50~60분 | 정상 복구·받은 도움·미완료 구분, 개인 학습 노트에 필요한 보충과 다음 질문 연결 |

개인 학습 시간을 고정된 2~3시간으로 제한하지 않는다. 필수 범위를 먼저 공부하고 실제 막힘에 따라 시간을 배분한다. 주차를 미리 분할하거나 필수 기준을 낮추지 않으며, 개인 공부 후에도 해결되지 않는 항목만 보충한다. C04/C08/C12/C16은 해당 주 기존 설명·실습을 대체하고 점검을 별도로 더하지 않는다. 한 사람의 답·팀 합의·파일 제출은 개인 이해/직접 수행의 증거가 아니다.

두 실험을 진행하고 각자의 이해를 확인하는 것이 필수다. 계산이나 조회에 시간이 더 걸리면 보조 질문·시험 연계·선택 데모를 줄인다. 환경 때문에 제공 자료로 공부했다면 개념 확인과 본인 실행 미완료를 나눈다. 긴 전체 발표를 추가해 실습을 밀어내지 않는다.

## 선택 데모와 완료 판정

격리 마스크 변경은 필수 과제가 아니다. 선택 실험을 하지 않았다는 이유로 필수 실습을 미완료로 기록하지 않는다. 실행을 선택한 경우 [Linux 안내](../../labs/week-02/LINUX.md)의 격리 네임스페이스/veth에서 C1→A만 `/26`→C1 복구와 자원 정리를 확인한다. 기본 시연의 조회/요청 방향은 A→B이며 B→A를 실측했다고 쓰지 않는다. 실제 관찰하지 못한 동작은 예상/제공 분석으로 구분한다.

| 항목 | 독립 확인의 기준 | 보충이 필요한 경우 |
| --- | --- | --- |
| 개념/추론 | 주소·접두사·경로·응답을 구별하고 C1/C2 양쪽 범위와 그 이유를 설명 | 숫자만 맞힘, 같은 범위=통신 성공으로 단정 |
| P1 직접 수행 | 자기 VM 출력에서 실제 값·선택 경로와 관찰 범위를 읽음 | 접속/도구 미준비, 짝/제공 출력만 봄 |
| P2 직접 수행 | 손계산·검산과 바뀐 조건 하나를 독립 확인 | 본인 검산/조건 변경 미실시 |
| 설명/다음에 확인할 것 | 소그룹 후속 질문에 현재 근거와 더 볼 것을 답함 | 발표자 답을 읽기만 함, 조회를 실제 응답으로 표시 |

한 명의 설명이나 실습 성공으로 다른 사람의 이해·직접 수행을 대신하지 않는다. 이번 실습으로 확인하는 것은 주소·경로·계산이다. 정책·NAT·서비스 정상 여부는 별도 관찰이 필요하다. 다음 회차에는 선택 분량을 줄여 막힌 필수 항목을 보충한다.
