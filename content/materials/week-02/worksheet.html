2주차 — 함께 찾아 공부할 질문

IP가 비슷한 두 VM의 통신을 중심 질문으로 함께 검색·공부한다. 공식 자료·CIDR·기존 VM 조회를 연결해 한 명이 설명하고 조건을 바꿔 확인한다. 보조 질문은 선택이며 답은 별도 해설에 둔다.

중심 질문 · W02-Q1

IP가 비슷한 두 VM은 같은 망으로 바로 통신할 수 있을까?

C1: A=192.0.2.10/24, B=192.0.2.70/24. C2: A만 192.0.2.10/26, B는 /24 그대로다. 두 카드 모두 각 인터페이스의 직접 연결 경로 외에는 다른 경로가 없다고 가정한다. 실제 VM 주소를 바꾸는 과제가 아니라 계산·추론용 사례다.

함께 찾아 답할 것은 다음 세 부분이다. 세 번의 독립 발표를 요구하지 않는다.

  1. 원리와 이유: 두 주소만으로 무엇을 판단할 수 있고 접두사가 더 있어야 알 수 있는 것은 무엇인가? C1/C2에서 양쪽 범위를 계산한다.
  2. 조건 변경: A만 접두사가 바뀌면 A와 B의 판단이 같을까? 주소 범위를 확인하면 실제 통신 성공도 확정되는가?
  3. 다음 관찰: 자기 VM의 현재 경로는 어떤 명령·출력으로 확인할까? 경로가 보이는 것과 상대가 응답했다는 것은 같은 증거인가?

먼저 함께 찾아보기의 공식 자료 두 곳과 검색어를 이용한다. 필요한 개념은 핵심 3개, 이유·그림·계산은 개념 교재에서 찾는다. 모르는 단어가 나오면 그 뜻을 묻는 작은 질문부터 풀고 다시 중심 질문으로 돌아온다.

함께 탐구하는 순서

순서 함께 할 일 실습으로 가져갈 것
질문 정리 비교할 주소·접두사·경로 가정을 확인. 처음 예상은 말하거나 짧게 메모 중심 질문과 모르는 용어
검색하고 공부 지정한 공식 문서의 절을 함께 읽고 범위 계산·경로 역할을 연결 읽은 절·그림·조건을 붙인 임시 답
한 명 설명 함께 찾은 답을 이유·근거와 함께 자기 말로 설명. 긴 발표 자료 불필요 계산과 출력 중 어디를 근거로 삼았는지
조건 바꿔 확인 다른 사람이 접두사·목적지 조건 하나를 바꿔 묻고 설명. 막히면 교재로 복귀 남은 질문과 필요한 실습
자기 실습 P1·P2의 조회·계산·검산을 각자 수행 실제 출력/개인 풀이의 위치

설명자는 질문이나 회차에 따라 교대한다. 한 사람의 답으로 전원이 이해했다고 처리하지 않고 소그룹에서 다른 사람도 짧은 조건 변경·출력 읽기를 확인한다. AI·검색 요약은 탐색 단서이며 공식 문서와 실제 출력으로 대조한다. 출처를 찾느라 막히면 진행자가 지정 절을 바로 제시한다.

선택 보조 질문

W02-Q2 · 같은 VM인데 왜 lo와 다른 인터페이스의 주소가 다를까?

1주차의 IP·포트·실행 위치가 헷갈릴 때 선택한다. 같은 VM의 두 SSH 창, 127.0.0.1, 실제 NIC 주소를 구별하고 어느 출력이 어떤 질문의 근거인지 찾아본다. 1주차 전체 실습을 다시 하지 않는다.

  • 찾을 곳: 개념 교재 1~2절, P1 주소·경로 조회.
  • 조건 변경: 자기 VM의 NIC 주소를 목적지로 조회했을 때도 반드시 그 NIC로 나갈까? 실제 선택은 조회로 확인하며 주소가 붙은 장치와 전달 경로를 같은 것으로 단정하지 않는다.

W02-Q3 · 사설 주소와 기본 경로가 보이면 클라우드 서비스가 정상일까?

계산 뒤 운영 판단을 더 연결할 때 선택한다. 주소 범주·커널 경로·정책·상대 서비스의 상태를 구별하고, 현재 증거로 확인한 것과 이후 확인할 것을 나눈다. 이번 주에 방화벽·NAT·서비스를 새로 구성하지 않는다.

  • 찾을 곳: 주소 종류, 경로 읽기.
  • 조건 변경: 기본 경로가 있어도 더 구체적인 경로가 있으면 어느 쪽을 볼까? 자세한 최장 접두사 선택은 7주차에 이어간다.

설명과 조건 변경으로 확인

공동 탐구 뒤 P1·P2에서 각자의 실제 조회·계산·검산을 확인한다. 카드 조건을 바꿀 때는 호스트 설정이 아니라 종이/검산기 입력만 바꾼다. 같은 네트워크 범위를 얻었다는 답과 직접 통신했다는 답을 구별한다.

답을 먼저 설명한 뒤 공동 질문의 분리 해설을 연다. 중심 질문·선택 질문의 답에 포함할 내용·흔한 오답·다음에 확인할 것을 대조한다. 개발 사례 W02-D1~D3는 중심 질문의 세 부분을 다시 확인하는 질문으로 사용하며 별도 과제로 더하지 않는다.

실습 증거와 선택 범위

P1/P2 개인 근거는 본인 파일에 한 번 보관한다. 제공 예제를 분석했다면 그 사실을 쓰고 본인 조회·검산은 보충한다. 설명자가 실행에 성공했더라도 다른 사람이 직접 실행한 것은 아니다.

격리 마스크 변경은 선택이다. 권한·격리·복구를 사전 확인한 진행자만 안내하며 관리 NIC·기본 경로를 바꾸지 않는다. 선택 실험을 하지 않아도 필수 실습은 완료할 수 있다. 선택 실행을 했다면 정상→A만 /26→복구와 자신이 만든 자원 정리를 실제 근거로 확인한다. 원리·계산·제공 분석을 선택 데모의 직접 실행으로 기록하지 않는다.
