선택 격리 실습의 참고자료

자료 확인한 범위 채택 판단
ip-netns(8), network_namespaces(7), ip-link(8) 네임스페이스의 독립 경로표·장치, ip netns add/exec/del, veth 링크. 선택 실습에 직접 사용. Linux 권한과 커널 지원은 현장에서 확인
iputils ping(8) -n, -c, -W와 종료 상태. 격리된 두 노드 사이에만 ICMP 한 번씩 보내며 실제 출력은 현장에서 기록
iproute2 소스 저장소 Linux 네트워크 도구의 공식 소스 미러와 GPL-2.0 표시. 명령 구현을 복제하지 않고 설치된 ip 도구를 사용

이 실습의 Python·셸 코드, 카드 질문, 합성 출력은 자체 작성했다. 외부 문서·코드의 본문이나 랩 파일을 복제하지 않고 링크와 필요한 읽을 범위만 제공한다. iproute2는 GPL-2.0 표시가 있는 별도 도구이며, Python은 PSF 라이선스의 별도 표준 라이브러리다. RFC·IANA 원문은 정의와 근거로 인용한 것이지 이 키트의 저작물로 주장하지 않는다.

실행 전 확인

제공 출력은 학습용 예시다. 실제 출력은 인터페이스 이름·설정·배포판에 따라 달라질 수 있다. 선택 격리 실습은 허가된 Linux에서 필요한 권한·커널 지원과 생성→변경→복구→정리 절차를 먼저 확인한다. SSH 관리 인터페이스나 기본 경로는 바꾸지 않는다.
