# 2주차 핵심 정리 — CIDR·경로·도달성

요약: CIDR 계산·경로 선택·실제 도달성을 세 문장으로 구별한다. 같은 주소 대역과 통신 보장, 사설 주소와 접근 허용의 혼동을 풀고 마스크가 다른 개발 환경을 진단한다.

- 사용법: [중심 질문](WORKSHEET.md)을 함께 공부할 때 필요한 세 개념을 찾는다. 설명이 막히면 연결된 교재·공식 문서로 돌아가고 P1/P2로 확인한다. 

## 꼭 기억할 개념 세 개

### W02-K1 · CIDR은 주소 범위를 나타낸다

**기억 문장:** IPv4 `/n`은 앞 n비트가 접두사라는 뜻이며 블록에는 2^(32-n)개 주소가 있다.

`/24`는 256개, `/26`은 64개 주소다. 이 수는 주소 개수이며 항상 그대로 사용할 수 있는 호스트 수는 아니다. 이번 일반 IPv4 서브넷 예제에서는 네트워크·브로드캐스트 주소를 제외하고, `/31`·`/32` 예외는 선택 범위다. [교재](CONCEPTS.md), [RFC 4632 §3.1](https://www.rfc-editor.org/rfc/rfc4632.html#section-3.1).

### W02-K2 · 실제 다음 전달 경로는 경로 조회로 확인한다

**기억 문장:** 접두사 계산은 출발점이며, 실제 선택된 `dev`·`via`·`src`는 `ip route get` 등에서 확인한다.

이번 단순 모형에서는 같은 서브넷에 직접 연결 경로가 있고 다른 목적지는 준비된 게이트웨이로 간다. ‘다른 망이면 언제나 기본 게이트웨이’라고 외우면 더 구체적인 경로·정책이 있는 경우를 놓친다. [주소·경로 실습](../../labs/week-02/LINUX.md), [ip-route(8)의 get](https://man7.org/linux/man-pages/man8/ip-route.8.html).

### W02-K3 · 범위 계산과 통신 성공은 다르다

**기억 문장:** 같은 서브넷이라는 계산은 주소 범위 판단이며, 양방향 전달·정책·서비스 정상을 증명하지 않는다.

보내는 쪽과 받는 쪽의 주소·접두사·경로 판단을 따로 본다. 가상 네트워크의 링크·정책 조건도 확인해야 한다. 아직 MAC·ARP 상세는 다음 주에 배운다. [교재](CONCEPTS.md), [제공 카드 C1·C2](../../labs/week-02/SAMPLE_OUTPUT.md).

## 헷갈리는 부분 두 가지

| 자주 섞는 설명 | 구별하는 방법 |
| --- | --- |
| 같은 `/24`면 같은 실제 네트워크라 통신한다 | 주소 계산과 실제 링크·가상망·정책·왕복 경로는 별도다. 양쪽 설정과 경로 증거를 확인한다 |
| 사설 IP면 안전하고 서로 접근 가능하다 | 주소 범주의 뜻과 방화벽·접근 권한은 별개다. 공인 주소 여부도 서비스 접근 성공을 보장하지 않는다 |

## 개발 상황으로 설명하기

**출처 구분: 스터디 자체 문항.** 아래는 개념 확인용 사례이며 특정 기업의 실제 출제 문제·빈출 문항을 뜻하지 않는다.

주소 카드 A는 `192.0.2.10/26`, B는 `192.0.2.70/24`다. 양쪽 모두 해당 인터페이스의 직접 연결 경로만 있고 다른 경로는 없다. 주소는 문서용 예시이며 실행 대상이 아니다.

1. **W02-D1 · 설명:** 양쪽 네트워크 범위와 상대를 같은 서브넷으로 보는지 계산하라.
2. **W02-D2 · 조건 변경:** A를 `/24`로 바꾸면 실제 통신 성공까지 확정할 수 있을까?
3. **W02-D3 · 진단:** 주소가 비슷하다는 주장 대신 무엇을 조회하고 어떤 변경을 피해야 할까?

중심 질문의 설명→조건 변경→진단 발문으로 재사용한다. 다른 세 문제를 추가로 부과하지 않는다. 먼저 말하거나 짧게 적은 뒤 [개발 질문 해설](ANSWERS.md#개발-질문-해설)을 연다. 해설을 읽었다는 사실로 직접 수행·독립 설명 완료를 표시하지 않는다.

## 다음 주에 다시 설명하기

A만 /26이고 B는 /24일 때 두 호스트의 판단은 왜 같지 않을 수 있는가? 다음 주 시작의 기존 복습 시간에 조건 하나를 바꾸어 다시 묻는다. 막히면 위 교재로 돌아가고 선택 분량을 줄인다.
