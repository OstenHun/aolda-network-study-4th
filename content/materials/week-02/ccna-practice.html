2주차 공개 시험 문항·CCNA 연계 연습

대학에서 공개한 과거 시험 3문항과 CCNA 기출 표방 사이트 1문항을 출처·한계와 함께 풀고, 자체 보충 2문항으로 /24·/26 계산을 연결한다. 실제 CCNA 출제 여부는 확인되지 않았다.

사용 순서와 출처 구분

기본 복습 뒤의 선택 학습이다. 이번 주 범위로 더 풀고 싶다면 C1·C4·C5·C6을 고른다. /25 배분이 필요한 C2와 /19 계산이 필요한 C3은 확장이다. 각 문항에 답 / 계산·출력 근거 / 아직 확인할 사실을 적고 해설을 연다. 대학 PDF에는 풀이가 같은 파일에 들어 있으므로 먼저 아래 과제를 풀고 원문을 확인한다.

ID 실제 자료의 성격 정확한 원문 위치
C1 Brown 대학교가 이전 시험으로 공개한 2016년 CSCI 1680 중간고사 해설본 2016 Midterm, Q2(d), PDF 4쪽
C2 Duke 대학교가 게시한 2014년 CS 356 중간고사 샘플·해설본 2014 Midterm, Q2(a), PDF 5쪽
C3 UC San Diego가 게시한 2015년 CSE 123 중간고사 해설본 2015 Midterm, Q3(b)~(e), PDF 4쪽

C1~C3은 실제 대학 시험 자료이지만 CCNA 시험 기출은 아니다. C4는 사이트의 출제 주장만 확인되며 진위·Cisco 승인·재배포 권한을 확인하지 못했다. 외부 보기와 시험지 전체는 원문 링크에서 읽는다. 아래 한국어 과제는 원문을 통째로 옮긴 번역본이 아닌, 해당 문항에서 이번 주에 풀 부분을 가리키는 자체 학습 안내다. 문항별 출처 안내에서 원문 범위와 풀이 시 주의할 점을 확인한다.

공개된 과거 시험에서 풀기

C1. 마스크 변경 뒤 다음 전달 상대 — Brown 2016 Q2(d)

원문의 H1=192.168.1.5, H2=192.168.1.180, 게이트웨이=192.168.1.1 그림을 본다. 처음 두 호스트는 /24다. H1의 마스크만 255.255.255.128로 바뀌면, H1이 H2를 같은 서브넷으로 판단하는지와 H1이 패킷을 먼저 보내려는 상대가 바뀌는지를 적어라. 힌트: 이 /25는 마지막 묶음을 0~127, 128~255로 나눈다. 원문은 H2에게 실제로 도달할지까지 증명하는가?

C2. 하나의 /24를 세 LAN에 배분 — Duke 2014 Q2(a)

원문 Q2(a)는 192.168.1.0/24 하나에서 최대 100호스트 LAN 하나와 최대 50호스트 LAN 둘에 겹치지 않는 접두사를 배정한다. 세 LAN의 네트워크 주소·접두사·일반적인 사용 가능 호스트 수를 적어라. Q2(a)만 선택 확장으로 사용한다. /25는 /26 두 개보다 큰 구간이다.

C3. 마스크·네트워크·브로드캐스트 — UCSD 2015 Q3(b)~(e), 선택 확장

원문의 184.86.92.182 주소와 “기존 /16 크기의 범위를 8개로 동등 분할”이라는 조건을 읽는다. 결과 접두사 길이와 이 주소가 속한 네트워크·브로드캐스트를 계산하라. /19와 세 번째 옥텟 경계 계산은 2주차 필수 /24·/26 뒤에만 다룬다. 원문의 옛 주소 클래스 설명을 오늘날 주소의 자동 마스크 규칙으로 일반화하지 않는다.

CCNA 기출 표방 사이트에서 풀기

C4. RFC 1918의 목적 — ExamTopics Q94

사이트가 제시한 짧은 질문은 “Why was the RFC 1918 address space defined?”다. 원문 보기 A~D에 접근할 수 있으면 가장 적절한 하나를 고르고, 접근할 수 없으면 질문에 서술형으로 답한다. 이유를 RFC 1918의 사설 범위·주소 절약 설명과 연결하라. 원문 페이지 본문은 직접 확인하지 못했다. 이 사이트의 추천 답·투표는 공식 정답이 아니다.

자체 보충 문제

다음 두 문제는 외부 기출의 번역·복제가 아닌 새 문제다. 데이터는 가상 사례다.

C5. /26의 서로 다른 구간

10.5.7.70/26인 호스트가 10.5.7.130을 목적지로 한다. 아래 중 주소·접두사만으로 확정할 수 있는 설명은?

  • A. 두 주소는 같은 /26이므로 게이트웨이 없이 직접 전달한다.
  • B. .70의 구간은 .64–.127이고 .130은 다른 구간이다. 실제 전달에는 경로가 더 필요하다.
  • C. .127은 이 호스트의 첫 사용 가능 주소다.
  • D. 서로 다른 구간이므로 실제 통신은 반드시 실패한다.

C6. 같은 범위여도 성공은 미확정

VM A=10.5.7.70/26, VM B=10.5.7.75/26이고 A의 ping이 실패했다. 가장 타당한 다음 설명은?

  • A. 주소가 같은 서브넷이라면 실패 출력은 반드시 잘못된 것이다.
  • B. 두 주소는 계산상 같은 서브넷이다. 양끝 인터페이스·경로·링크와 ICMP 허용 여부를 실제 출력으로 확인한다.
  • C. 기본 게이트웨이가 없으면 같은 서브넷 목적지에는 언제나 경로가 없다.
  • D. ping 실패만으로 B의 IP 주소가 틀렸다고 확정한다.

마무리

원문 문제 하나와 자체 문제 하나를 짝에게 설명한다. 다른 사람의 답이나 제공 해설은 자기 VM의 실측이 아니다. 구판·타 과정 문항이 현재 CCNA 시험의 출제 범위나 난도를 대표한다고 가정하지 않는다.
