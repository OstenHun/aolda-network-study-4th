# 2주차 — IP가 비슷하면 같은 망일까?

요약: 함께 질문을 찾아 공부하고 CIDR·경로·도달성을 구별한다. 기존 VM 조회와 주소 카드 계산·검산으로 설명을 확인한 뒤 분리 해설로 복습한다. 기본 실습은 읽기 전용 조회·계산이며 격리 설정 변경은 선택이다.

## 이번 주 함께 풀 질문

**IP가 비슷한 두 VM은 같은 망으로 바로 통신할 수 있을까?**

1주차에서 사용한 VM에 다시 접속한다. 새 VM이나 서버를 만들지 않고, 기존 주소·접두사·경로를 읽어 질문의 답을 찾아간다. 이번에는 같은 VM의 주소와 경로를 읽는다.

가상 카드 C1은 A=`192.0.2.10/24`, B=`192.0.2.70/24`다. C2에서는 A만 `/26`으로 바꾼다. 주소가 비슷해도 판단이 달라질까? 계산한 답을 자기 VM의 현재 경로와 어떻게 연결할까? 카드의 주소는 문서 예시이며 실제 VM에 설정하지 않는다.

[함께 찾아 공부할 질문 열기](WORKSHEET.md)에서 시작한다. 답을 미리 완성해 올 필요는 없다. 공식 자료를 함께 읽고 한 명이 근거로 설명한 뒤, 다른 사람이 조건을 바꿔 설명을 확인한다. 설명자는 회차마다 교대한다.

## 필수·선택과 완료 기준

| 구분 | 이번 주 범위 | 확인할 근거 |
| --- | --- | --- |
| 필수 개념 | IPv4·인터페이스, `/24`·`/26`의 비트/주소 범위, 경로·게이트웨이와 도달성의 차이 | C1/C2 풀이와 실제 출력에서 `dev`·`via`·`src` 또는 없는 값/오류를 읽은 설명 |
| 필수 실습 P1 | 1주차에 쓰던 승인된 Linux VM의 주소·경로·루프백/허용 목적지 경로 조회 | 본인이 실행한 명령·실제 출력과 관찰 위치. 경로 조회를 응답 확인으로 표시하지 않음 |
| 필수 실습 P2 | C1 양쪽 `/24`, C2 A만 `/26` 손계산→Python 검산→카드 조건 하나 독립 변경 | 양쪽 범위·방향별 판단, 검산 결과, 바꾼 조건의 근거 |
| 필수 설명 확인 | 원리·이유→조건 변경→다음에 볼 근거 | 한 명이 설명한 뒤 다른 사람도 소그룹에서 조건을 바꿔 답하거나 출력을 읽기 |
| 선택 | 격리 마스크 변경·복구, VLSM·`/31`·`/32`, 공개 시험·CCNA 연계 | 선택 실험을 하지 않아도 필수 실습은 완료할 수 있다. 실행했다면 실제 조건·결과·복구·정리를 별도 확인 |

**VM 구조를 설명해 보기:** 자기 VM의 주소/접두사·연결 경로·기본 경로와 아직 모르는 구간을 작은 그림으로 표시한다. 이 그림으로 VM이 연결된 구조를 설명한다. 정책·서비스·NAT가 정상인지는 별도로 확인해야 한다. “주소 범위 판단 / 커널이 선택한 경로 / 실제 상대의 응답” 중 무엇을 확인했는지 말한다. 이번 필수 실습은 첫 두 항목을 다룬다.

원본 출력·손계산·검산은 [개인 실습 증거](../../labs/week-02/LINUX.md#개인-실습-증거-보관)에 한 번 보관한다. 함께 찾은 답을 설명하고 조건 변경·실습 결과로 확인한다. 필요한 메모는 자유롭게 한다. 접속이 막히면 [제공 예제](../../labs/week-02/SAMPLE_OUTPUT.md)를 분석하고 P1 직접 수행을 보충한다.

## 두 모임에서 사용하는 방법

사전 공동학습은 질문 확인→공동 탐색/공부→한 명 설명→조건 변경·실습 준비에 60분을 제안한다. 오프라인은 P1·P2·소그룹 확인·기록 보관에 60분을 제안한다. 모임의 시간 배치는 [진행자 안내](FACILITATOR.md)를 참고한다.

필수 실습이 밀리면 선택 데모·시험 연계를 줄이고 보충할 항목을 남긴다. 개인 학습 주 2~3시간 안에서 교재의 필요한 절·복습·재현을 배치하며 긴 발표 준비와 새로운 필수 읽기를 더하지 않는다.
