2주차 — IP가 비슷하면 같은 망일까?

함께 질문을 찾아 공부하고 CIDR·경로·도달성을 구별한다. 기존 VM 조회와 주소 카드 계산·검산으로 설명을 확인한 뒤 분리 해설로 복습한다. 기본 실습은 읽기 전용 조회·계산이며 격리 설정 변경은 선택이다.

이번 주 함께 풀 질문

IP가 비슷한 두 VM은 같은 망으로 바로 통신할 수 있을까?

1주차에서 사용한 VM에 다시 접속한다. 새 VM이나 서버를 만들지 않고, 기존 주소·접두사·경로를 읽어 질문의 답을 찾아간다. 이번에는 같은 VM의 주소와 경로를 읽는다.

가상 카드 C1은 A=192.0.2.10/24, B=192.0.2.70/24다. C2에서는 A만 /26으로 바꾼다. 주소가 비슷해도 판단이 달라질까? 계산한 답을 자기 VM의 현재 경로와 어떻게 연결할까? 카드의 주소는 문서 예시이며 실제 VM에 설정하지 않는다.

함께 찾아 공부할 질문 열기에서 시작한다. 답을 미리 완성해 올 필요는 없다. 공식 자료를 함께 읽고 한 명이 근거로 설명한 뒤, 다른 사람이 조건을 바꿔 설명을 확인한다. 설명자는 회차마다 교대한다.

질문에서 실습과 해설로

흐름 사용할 자료 함께 할 일
1. 질문을 나누고 찾아보기 중심 질문·선택 보조 질문 → 함께 찾아보기 AWS의 CIDR 설명과 Linux 경로 조회 문서의 지정 부분에서 출발. 검색어·읽을 절·돌아올 질문을 안내한다
2. 필요한 개념 익히기 핵심 개념 3개 → 필요한 개념 교재 절 접두사와 범위, 경로 선택, 실제 도달성을 나눠 설명. 막히는 부분만 교재로 돌아간다
3. 내 인스턴스로 확인하기 기존 VM 실습 자기 주소·경로 조회 한 묶음, C1/C2 손계산·Python 검산 한 묶음. 예제와 실제 출력을 구분한다
4. 한 명 설명·조건 변경 질문으로 돌아가기 함께 찾은 답을 근거로 설명하고 다른 사람이 접두사·목적지 조건 하나를 바꿔 확인. 개인 실습은 각자 수행
5. 답과 근거 비교하기 공동 질문의 분리 해설 → 복습 8문항·복습 해설 먼저 자기 답을 설명한 뒤 필수 답안 요소·흔한 오답·다음 진단과 비교. 복습은 개인 시간에 진행

이 표는 자료를 찾는 경로다. 같은 내용을 여러 번 읽거나 세 질문에 모두 발표하는 과제가 아니다. 중심 질문 하나를 필수로 하고 보조 질문은 막힌 개념에 따라 선택한다. 지정 원문은 공동 탐구 시간에 함께 읽는다.

필수·선택과 완료 기준

구분 이번 주 범위 확인할 근거
필수 개념 IPv4·인터페이스, /24·/26의 비트/주소 범위, 경로·게이트웨이와 도달성의 차이 C1/C2 풀이와 실제 출력에서 dev·via·src 또는 없는 값/오류를 읽은 설명
필수 실습 P1 1주차에 쓰던 승인된 Linux VM의 주소·경로·루프백/허용 목적지 경로 조회 본인이 실행한 명령·실제 출력과 관찰 위치. 경로 조회를 응답 확인으로 표시하지 않음
필수 실습 P2 C1 양쪽 /24, C2 A만 /26 손계산→Python 검산→카드 조건 하나 독립 변경 양쪽 범위·방향별 판단, 검산 결과, 바꾼 조건의 근거
필수 설명 확인 원리·이유→조건 변경→다음에 볼 근거 한 명의 공동 설명 뒤 다른 사람도 소그룹에서 짧게 조건 변경/출력 읽기 확인
선택 격리 마스크 변경·복구, VLSM·/31·/32, 공개 시험·CCNA 연계 선택 미실시는 필수 미완료가 아니다. 실행했다면 실제 조건·결과·복구·정리를 별도 확인

이번 주의 클라우드 운영 연결: 자기 VM의 주소/접두사·연결 경로·기본 경로와 아직 모르는 구간을 작은 그림으로 표시한다. 이는 이후 운영 기준의 구조 설명을 준비하는 부분이며 정책·서비스·NAT까지 운영 완료했다는 뜻은 아니다. “주소 범위 판단 / 커널이 선택한 경로 / 실제 상대의 응답” 중 무엇을 확인했는지 말한다. 이번 필수 실습은 첫 두 항목을 다룬다.

원출력·손계산·검산은 개인 실습 증거에 한 번 보관한다. 함께 찾은 답을 설명하고 조건 변경·실습 결과로 확인한다. 필요한 메모는 자유롭게 한다. 접속이 막히면 제공 예제를 분석하고 P1 직접 수행을 보충한다.

두 모임에서 사용하는 방법

사전 공동학습은 질문 확인→공동 탐색/공부→한 명 설명→조건 변경·실습 준비에 60분을 제안한다. 오프라인은 P1·P2·소그룹 확인·기록 보관에 60분을 제안한다. 모임의 시간 배치는 진행자 안내를 참고한다.

필수 실습이 밀리면 선택 데모·시험 연계를 줄이고 보충할 항목을 남긴다. 개인 학습 주 2~3시간 안에서 교재의 필요한 절·복습·재현을 배치하며 긴 발표 준비와 새로운 필수 읽기를 더하지 않는다.

실습 파일과 선택 자료

  • Python 검산기: 기존 표준 라이브러리 도구. 손계산 뒤 사용하며 실제 통신을 시험하지 않는다.
  • 코드 읽기: 입력·판단·출력과 선택 셸 실험의 흐름을 따라 읽는다.
  • 격리 데모: 진행자가 권한·격리·복구를 사전 확인했을 때만 선택 실행. 관리 NIC·기본 경로를 변경하지 않는다.
  • 추가 탐구 · 시험 연계·시험 해설: 필수 완료 후 선택.
  • 출처와 지정 범위 · 실습 출처: 공식 근거·참고 글·자체 문제의 구분.

자료 읽기와 답안 보관

이 사이트에서 질문·개념·실습·해설을 이어서 읽는다. 외부 원문에는 인터넷이 필요하다. 공동 질문은 함께 읽고 설명하는 자료다. 복습·시험 연계 화면에서 답안을 입력했다면 이동 전에 Markdown으로 내려받고 파일을 확인한다.

기존 VM의 읽기 전용 P1 조회와 P2 손계산·검산이 필수다. 격리 설정 변경은 선택이며 실제 Linux 수행·개인별 설명 여부는 각자의 근거로 확인한다.

다음은 3주차 LAN·MAC·ARP·ICMP다. “어느 경로로 보낼까?”에서 “그 링크의 다음 상대를 어떻게 찾을까?”로 이어간다. 개념 화면의 모형은 양쪽 접두사 동시 변경, C2와 선택 데모는 A만 변경이므로 조건을 구분한다.
