1주차 복습 문제

풀기 전에

아래 데이터는 모두 문제용 예시다. 자신의 실측으로 기록하지 않는다. 문항마다 답과 근거 한 문장을 적는다. 해설은 작성 뒤에 연다.

기본 문항

  1. 개인 PC의 SSH 창 A에서 Python, 창 B에서 curl을 같은 VM에 실행했다. 이번 HTTP 요청·응답이 오가는 호스트는 몇 대이며, 이를 주고받는 주요 응용 프로세스는 무엇인가? 개인 PC는 어떤 역할인가?
  2. 127.0.0.1:53120 → 127.0.0.1:8080 요청의 응답 방향을 그려라. 어느 것이 임시 포트인가? 53120이 다음에도 같아야 하는가?
  3. 개인 PC에서 http://127.0.0.1:8080/echo를 요청했는데 VM의 서버 로그가 없다. VM 서버의 고장이라고 단정할 수 있는가? 다음 확인 두 가지를 적어라.
  4. > GET /missing HTTP/1.1, < HTTP/1.1 404 Not Found, {"error":"not found"}에서 메서드·경로·상태·본문을 구별하라. TCP 연결 실패의 증거인가?
  5. 위 요청의 curl 종료 코드가 0이었다. HTTP 404와 모순인가? echo $? 앞에 pwd를 실행하면 무엇이 문제인가?
  6. 서버를 중지한 뒤 curl: (7) Failed to connect가 나왔다. HTTP 상태 7인가? 서버 로그가 새로 없다는 것만으로 원인을 확정할 수 있는가?
  7. Linux VM 내부 요청을 개인 PC Wi-Fi에서 캡처했더니 HTTP가 없다. 캡처 위치를 어떻게 바꿀까? 캡처 셸·파일·Wireshark 위치를 그려라.
  8. 제공 캡처의 서버 포트는 59995다. tcp.port == 8080에 아무것도 나오지 않을 때 첫 수정은? 이 파일을 분석하면 직접 Linux 캡처 완료인가?
  9. 메시지·경로·포트를 한꺼번에 바꿨더니 404가 연결 오류로 바뀌었다. 왜 해석하기 어려운가? 재실험 순서를 적어라.
  10. “TCP가 성공하면 HTTP는 항상 200이다”, “패킷 하나는 HTTP 메시지 하나다”, “listening이면 외부 PC에서도 접속된다”를 각각 고치고 필요한 증거를 적어라.

마무리

추가로 CCNA 연계 연습을 선택해서 푼다. 외부 원문 3문항과 자체 보충 2문항은 15~20분 분량이다. 기출 표방 사이트 질문 C6은 선택 5분이며 실제 출제 여부는 미확인이다. 해설은 풀이 뒤에 연다.

내가 틀렸던 예상 하나를 골라 실제 출력 또는 제공 예제의 어떤 부분이 설명을 바꿨는지 3문장으로 쓴다. 1~8번에서 막히면 교재의 해당 개념과 실습을 다시 연결한다. 점수만으로 학습 완료를 결정하지 않고 각자의 실습 증거 파일과 팀 활동의 근거 위치·설명 변화를 함께 확인한다.
