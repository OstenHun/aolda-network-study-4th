1주차 학습 자료

요청 하나를 끝까지 따라가기

개념과 Linux 실습을 연결하고, 함께 설명·토론하며 복습하는 1주차 학습 안내다.

기억할 개념과 구별 이번 주 핵심·혼동·개발 질문을 읽기 마지막 5분에 사용합니다. 전체 개념 색인 · 면접·개발 참고자료도 연결했습니다.

VM에 아직 접속하지 않았다면
SSH 학습 홈에서 VM·주소·VPN을 준비하고, 본인에게 허용된 계정과 인증 방식으로 접속한다. 접속을 확인한 뒤 아래 Linux 실습으로 돌아온다.

처음 읽는다면
아래에서 개념 교재 → Linux 실습 → 팀 활동 → 복습 문제 순서로 연다. 상세 실험 증거는 개인 실습 기록이나 별도 파일로 보관하고, 팀 활동에는 질문·근거 위치·바뀐 설명을 남긴다. 셸 명령을 처음 쓴다면 Linux 안내의 첫 부분부터 따라간다.

01 · 먼저 읽기

개념 교재

그림과 질문으로 호스트·루프백·주소·포트·HTTP를 익힙니다. 약 30분.

02 · 환경 준비와 실행

Linux 실습

같은 Linux의 Python 서버와 curl로 200·404·연결 실패·복구를 관찰합니다.

03 · 함께 개념 다지기

팀 활동

같은 질문을 생각하고 돌아가며 설명·질문합니다. 근거를 확인하고 팀 기록 세 가지와 개인 마무리 두 줄을 남깁니다.

04 · 혼자 다시 풀기

복습 문제

10문항을 먼저 풀고 근거를 적은 다음 별도 해설과 비교합니다. 약 20분.

원문과 함께 읽기

roadmap.sh 참고 글로 배우기에서 포트·HTTP 원문 지정 부분을 읽고 설명·실습 질문으로 이어갑니다. 필수 10분은 개념 학습 30분에 포함하며 나머지는 선택입니다.

모임에서 함께

팀 활동의 질문 세 개로 개념을 다집니다. 생각 → 설명 → 질문 → 근거 확인 순서로 진행하고 기록은 마지막에 짧게 남깁니다.

개인 실습 기록에서 먼저 예측하고 네 상태의 상세 출력·패킷을 남깁니다. 명령은 Linux 안내부터 따라가세요. 이 화면의 메모도 자동 저장되지 않으므로 모임이 끝날 때 내려받습니다.

문제를 푼 다음

복습 해설에서 내 답과 비교하고, 틀린 이유는 복습 문제의 수정한 설명 칸에 남깁니다. 여유가 있다면 CCNA 연계 연습을 푼 다음 별도 해설을 보세요. 외부 원문 C1~C3은 연결된 출판사 PDF에서 읽으며, C6은 선택입니다.

막히거나 더 알아보고 싶다면

  • 제공 캡처 안내 — 직접 캡처가 막힐 때 예제를 분석하고 증거 종류를 표시합니다.
  • 공식 자료 읽기 안내 — 필요한 부분과 읽는 시간을 확인합니다.
  • 선택 탐구 — 필수 네 상태를 마친 뒤 한 문제만 더 실험합니다.
  • 진행자 안내 — 환경 점검과 모임 운영 참고.

코드를 처음 읽는다면

코드 읽기 안내에서 실제 server.py를 다섯 단계로 따라갑니다. Python 문법의 최소 뜻, HTTP 출력과 코드의 연결, 작은 변경 문제를 함께 봅니다. Node 클라이언트는 선택으로 분리했습니다.

실습 파일

Python 서버 server.py가 기본 실습 파일입니다. 전체 폴더를 전달받았다면 labs/week-01/server.py 경로를 유지하세요. Node 클라이언트는 선택이며 처음부터 설치할 필요가 없습니다.

현재 자료와 예시 출력은 참가자가 직접 실행한 결과는 아닙니다. 아올다 VM 접속, 실제 Linux 실행과 캡처는 각자의 환경에서 확인해야 합니다. HTML 입력 내용은 자동 저장되지 않으므로 회차마다 내려받으세요.
