외부 HTTP 과제의 사이트를 호출하거나 브라우저 설정을 바꾸는 것은 이번 필수 과제가 아니다. 우리 실습은 curl의 HTTP/1.1과 Linux lo를 사용하므로 원문에 있는 브라우저 캐시·VPN·QUIC 관련 준비를 그대로 적용하지 않는다. 메시지를 관찰하는 방법을 읽고 자체 서버에 적용한다.

확인 범위와 저작권

공식 문서와 참고 글의 읽을 범위를 교재에 연결한다. 본문을 확인하지 못한 자료와 대체 자료는 원문 대응표에 구분했다. 외부 원문은 링크로 안내하며 본문·해답을 길게 복제하지 않는다.

핵심 정리와 개발 질문의 근거

핵심 정리는 기존 교재와 공식 원문을 연결한 자체 설명이며 개발 사례·해설은 스터디 자체 작성이다. 공개 저장소·공식 문서 선정 기록에 읽은 절·채택 범위·보류 이유를 정리했다. 회사별 실제 면접 출제·빈도는 확인하지 않았다.
