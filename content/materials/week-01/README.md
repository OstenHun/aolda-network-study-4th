# 1주차 학습 묶음 — 요청 하나를 끝까지 따라가기

요약: Linux 한 대에서 요청·응답·실패를 배우는 학습 자료다. 개념 읽기, 개인 실습, 짝 설명, 복습 순서로 사용한다. 자기 출력과 패킷을 근거로 설명한다.

## 이번 주 완료 기준

각자 200·404·서버 중지·재시작의 명령과 양쪽 출력을 남긴다. 출력과 패킷을 주소·포트로 연결하고, 짝이 지정한 조건 하나를 바꿔 도움 없이 다시 실행한다. IP/포트, 루프백, 404와 연결 실패를 자기 말로 설명한다. 패킷은 직접 캡처 또는 제공 예제 분석으로 표시한다. 환경이 막혀 실행을 못 했다면 개념 활동은 이어가되 직접 실행은 미완료다.

패킷 분석은 정상 요청 한 흐름이 필수다. 추가 404·중지·복구 패킷 비교는 선택이며 못 본 항목은 미관찰로 남긴다. 답안은 자동 저장·화면 간 자동 이동되지 않는다. 내려받은 `.md` 파일은 메모장으로 열 수 있고, 학습 홈으로 돌아가기 전에도 입력을 보관한다.
