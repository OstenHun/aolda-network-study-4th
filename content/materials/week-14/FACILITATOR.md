# 14주차 · 진행자 안내

요약: 개인 공부에서 개념·문제·실습을 준비하고 오프라인 한 번에서 설명·조건 변경·직접 수행을 확인한다. 준비·복구와 제공 분석의 경계를 지키며 막힌 필수 항목을 보충한다.

## 시작 전에 재현하기

[실습 준비](LINUX.md)의 Python/curl/ss·루프백 세 포트·실행 파일을 허가된 Linux에서 확인한다. a의 정상→0.2초 대기→복구와 두 서버의 분산·b 제외/복귀·b 정지/재시작을 리허설하고 정리까지 확인한다. 서버와 프록시는 전경 셸로 실행해 소유자를 분명히 한다. 기존 13주 서비스·관리 SSH·보안 그룹을 바꾸지 않는다. 환경이 미준비면 제공 사례로 분석하고 직접 전환은 환경을 준비한 뒤 각자 보충한다.

## 한 주의 개인 공부와 오프라인 확인

개인 준비는 [학습 홈의 정리 안내](README.md#personal-notes)에 따라 주요 질문과 내 답·헷갈리는 개념 비교·꼭 기억하고 이해할 핵심을 살핀다. 노트 분량을 평가하지 않고 이유·조건 변경·관련 실습 근거로 확인한다. 모임 뒤에는 틀린 설명과 남은 보충만 기존 개인 노트에서 고치며 중복 제출을 요구하지 않는다.

[학습 홈의 개인 공부 범위와 세 확인 질문](README.md#weekly-study)을 오프라인 모임 전까지 준비한다. 모임은 그 주 학습을 마무리하고 남은 보충을 정하는 자리다. 개념·공식 지정 절·복습과 준비된 실습의 정상→변경→복구는 개인 공부에서 시도한다. 모임 전 완성 답안·발표 자료를 요구하지 않으며 막힌 질문과 본인 근거를 가져오게 한다. 진단 원인을 가리는 과제는 정상 기준과 도구까지만 준비한다.

오프라인은 한 번의 모임에서 **설명 → 새 조건 → 본인 실습/분석 확인 → 보충 결정**으로 진행한다. 아래 60분은 시간 배분 예시이며 모임 길이나 추가 회차를 확정하는 표가 아니다.

| 시간 예시 | 진행자가 확인할 것 |
| --- | --- |
| 0~10분 | 개인 공부에서 막힌 질문과 2~4학습 단위 전 개념 하나를 골라 근거로 설명 |
| 10~25분 | 학습 홈의 중심 질문 → 조건 변경. 소그룹에서 설명자/확인자 교대 |
| 25~50분 | 두 계산 묶음과 제공 분포/연결 사례 분석, A 정상/지연/복구, B 분산/제외/정지/복구. 이미 수행했다면 근거를 보고 다른 한 조건의 판단·변경·복구 확인 |
| 50~60분 | 정상 복구·받은 도움·미완료 구분, 개인 학습 노트에 필요한 보충과 다음 질문 연결 |

개인 학습 시간을 고정된 2~3시간으로 제한하지 않는다. 필수 범위를 먼저 공부하고 실제 막힘에 따라 시간을 배분한다. 주차를 미리 분할하거나 필수 기준을 낮추지 않으며, 개인 공부 후에도 해결되지 않는 항목만 보충한다. C04/C08/C12/C16은 해당 주 기존 설명·실습을 대체하고 점검을 별도로 더하지 않는다. 한 사람의 답·팀 합의·파일 제출은 개인 이해/직접 수행의 증거가 아니다.

## 공동 탐색과 설명 교대

[W14-D1](WORKSHEET.md)을 중심 질문으로 사용한다. [공식 출처](SOURCES.md)에서 RFC5681의 cwnd/rwnd·slow start/혼잡 회피 지정 문단과 curl 시간 정의만 읽는다. 영어가 막히면 cwnd는 송신 측 혼잡 한도, rwnd는 수신 측 광고 한도, outstanding은 보냈지만 아직 ACK되지 않은 데이터, first byte는 첫 응답 byte로 풀어 교재의 식·시간축에 대응한다. 전체 RFC를 필독으로 늘리지 않는다.

첫 설명자는 가설과 관찰을 말하고 다음 사람은 health200·rwnd 축소·b 제외 중 조건 하나를 바꾼다. 다음 질문이나 회차에는 설명자를 교대한다. 발표자 외 참가자도 짧은 계산값 변경·출력 읽기와 개인 실험을 확인한다. [해설](ANSWERS.md)을 가리고 자기 말로 설명한 범위와 도움받은 설명을 구별한다.

## 판정과 다음 연결

필수 이론은 두 계산 묶음·그래프 설명, 직접 실습은 A/B에서 본인이 비교·복구한 근거로 확인한다. O04는 각자의 분산/전환, O05는 정상 기준·두 가설·관찰·복구로 확인한다. 직접 실행 미완료와 설명 확인 여부를 따로 나눈다. 9주 STP/LACP·10주 OSPF·11/13주 정책 등 앞선 미완료는 이번 제공 자료로 대체하지 않는다. 고정 팀 기록·개인 마무리 양식을 요구하지 않고 본인 원본을 필요한 만큼 한 번 보관한다.

15주 시작의 기존 복습에서는 “health만 자동 수집하면 실제 실패를 놓칠까?”를 묻는다. 자동화 본문·대규모 부하·관측 플랫폼을 앞당기지 않는다. [핵심 교재](CONCEPTS.md) · [색인](../CONCEPT_INDEX.md) · [학습 홈](README.md).
