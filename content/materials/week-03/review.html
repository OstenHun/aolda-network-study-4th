LAN · MAC · ARP · ICMP

3주차 복습 — 내 설명의 근거 찾기

LAN·MAC·ARP·ICMP를 앞선 HTTP·주소·경로 개념과 연결하는 자체 복습 8문항이다. 먼저 근거를 적고 별도 해설과 비교한다. 예시 출력은 아올다 실측이 아니다.

1. 복습 진단2. LAN·MAC3. 다음 홉4. ARP·캐시5. ICMP·ping
이 페이지의 목차
풀기 전에비교와 보충핵심 개념을 다시 찾을 때

풀기 전에

20분을 제안한다. 용어 하나로 끝내지 말고 “어떤 조건에서, 어떤 출력으로 알 수 있는가?”를 적는다. 해설은 답을 쓴 뒤 연다. 아래 주소와 MAC은 설명용이며 명령 실행 대상이 아니다. 실습 결과를 묻는 문제도 수행하지 않았다면 미수행으로 적는다.

Q1 — 앞선 관찰의 범위

어떤 학습자가 VM의 127.0.0.1:8080에서 HTTP 200·404·중지 뒤 연결 거부·복구를 관찰하고 lo에서 캡처했다고 하자. 이 자료로 ① 다른 학습자도 모두 실습했다, ② PC→VM SSH 경로가 캡처됐다, ③ VM 내부 프로그램의 HTTP/TCP 흐름을 관찰했다 중 무엇을 말할 수 있는가? lo에서 Ethernet ARP를 찾도록 요구해도 되는가?

Q2 — IP·port·MAC의 역할

VM의 curl이 다른 호스트의 HTTP 서버에 요청한다고 하자. 최종 목적지 IPv4, TCP 목적지 port, 첫 IP 패킷을 담은 Ethernet 프레임의 목적지 MAC은 각각 무엇을 식별하는가? HTTP 404를 받았을 때 “그 서버와 연결되지 않았다”고 설명할 수 있는가?

Q3 — 같은 링크의 상대

설명용 Ethernet LAN에서 A는 192.0.2.10/24, B는 192.0.2.70/24다. A의 경로 조회는 다음과 같다.

192.0.2.70 dev eth0 src 192.0.2.10

A의 이웃표에 B의 매핑이 없다고 가정한다. ARP 질문의 대상 IP, 요청 프레임의 목적지 MAC, 응답 뒤 ICMP Echo Request의 목적지 IP와 목적지 MAC을 쓰라. 실제 클라우드에서는 같은 /24 계산만으로 응답을 보장할 수 있는가?

Q4 — 다른 망의 상대

A에서 허가된 원격 목적지를 조회한 설명용 결과다.

198.51.100.20 via 192.0.2.1 dev eth0 src 192.0.2.10
192.0.2.1 dev eth0 lladdr 02:00:00:00:00:01 REACHABLE

NAT가 없는 단순 라우팅 모형이다. ARP가 필요하면 어느 IP를 묻는가? 첫 IP 패킷을 담은 프레임의 목적지 MAC과 IP 패킷의 목적지 IP를 각각 적고, 원격 서버 MAC이 이 출력에 없는 이유를 설명하라.

Q5 — 캐시가 있으면

캡처를 시작하고 ping을 2회 보냈다. ICMP 요청·응답은 보이지만 ARP 요청이 없다. 이웃 행에는 MAC과 REACHABLE이 보인다. “ARP가 필요 없는 네트워크”라고 결론 내려도 되는가? STALE은 “서버가 죽었다”는 뜻인가? 이번 기본 실험에서 캐시를 지우는가?

Q6 — 관찰이 막히면

① 이웃 행에 INCOMPLETE만 있음, ② 조회에 local ... dev lo가 보임, ③ tcpdump 권한이 없음, ④ 가상 NIC에서 자신의 흐름만 보임을 만났다. 각각 확인할 것과 기록해야 할 한계를 한 줄씩 적으라. FAILED만으로 HTTP 프로세스 상태를 알 수 있는가?

Q7 — ping과 HTTP

허가된 대상의 ping은 시간 초과지만 HTTP는 404를 반환했다. 어떤 서비스·프로토콜은 관찰됐고 무엇은 아직 모르는가? 반대로 ping이 응답하고 curl 연결이 거부됐다면 무엇을 추가 확인하는가? ICMP Echo에는 TCP의 port가 있는가?

Q8 — 독립 설명과 증거

자기 실험 또는 제공 trace 중 하나를 골라 최종 목적지 IP와 링크의 다음 상대를 그려라. “경로 결정 → 다음 홉 선택 → 이웃 매핑 → 프레임 전달 → ICMP 응답 해석”을 2분 설명으로 연결한다. 근거 줄/패킷 번호, 직접 실행 여부, 예상과 달랐던 점, 아직 모르는 점을 포함한다. 실제로 확인하지 않은 MAC·정책을 만들어 넣지 않는다.

비교와 보충

분리 해설과 대조해 바뀐 설명 하나를 남긴다. Q3·Q4가 막히면 다음 홉, Q5·Q6은 ARP, Q7은 ICMP를 다시 읽는다. 이후 TCP/UDP와 서비스 port의 차이는 4주차로 이어진다.

핵심 개념을 다시 찾을 때
