자료와 실제 관찰의 경계

개념 교재의 MAC·IP·인터페이스 이름·명령 출력·그림은 설명용 예시다. loopback에서 본 HTTP 패킷은 Ethernet ARP 관찰 결과가 아니다. 관찰 범위와 한계를 참고한다.

실습에서 근거를 얻을 때는 실제 인터페이스·허용된 목적지와 캡처 위치를 먼저 기록한다. 자기 VM 가상 NIC의 캡처로 물리 호스트 전체 패브릭을 보았다고 해석하지 않는다. 캐시 때문에 새 ARP가 안 보일 수 있고, ICMP 응답 여부만으로 HTTP 서비스 상태를 단정하지 않는다. 직접 캡처가 불가하면 자체 제작한 설명용 가상 패킷 예제 분석으로 개념을 확인하되 본인 VM 실행으로 기록하지 않는다. 대학 실습 PDF는 질문·관찰 방식의 참고이며 이 가상 패킷 예제를 캡처한 원본은 아니다.

핵심 정리와 개발 질문의 근거

핵심 정리는 기존 교재와 공식 원문을 연결한 자체 설명이며 개발 사례·해설은 스터디 자체 작성이다. 공개 저장소·공식 문서 선정 기록에 읽은 절·채택 범위·보류 이유를 정리했다. 회사별 실제 면접 출제·빈도는 확인하지 않았다.
