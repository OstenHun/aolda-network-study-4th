# 15주차 진행자 안내 · 같은 기준으로 비교하도록 돕기

요약: 개인 공부에서 개념·문제·실습을 준비하고 오프라인 한 번에서 설명·조건 변경·직접 수행을 확인한다. 준비·복구와 제공 분석의 경계를 지키며 막힌 필수 항목을 보충한다.

## 먼저 준비할 것

[실습 준비](LINUX.md)의 Python/curl/ss·미사용 포트·파일 네 개를 확인한다. 기존 Linux 한 대의 루프백에서 진행하며 실제 접속값은 자료에 옮기지 않는다. 진행자는 정상→eof→원복과 HTTP 200/404→중지→복구를 미리 재현하고 리스너 정리를 확인한다. 도구·권한이 없으면 [가공 사례](../../labs/week-15/observations.txt)로 함께 분석하고 각자 직접 수행 보충을 남긴다.

## 한 주의 개인 공부와 오프라인 확인

개인 준비는 [학습 홈의 정리 안내](README.md#personal-notes)에 따라 주요 질문과 내 답·헷갈리는 개념 비교·꼭 기억하고 이해할 핵심을 살핀다. 노트 분량을 평가하지 않고 이유·조건 변경·관련 실습 근거로 확인한다. 모임 뒤에는 틀린 설명과 남은 보충만 기존 개인 노트에서 고치며 중복 제출을 요구하지 않는다.

[학습 홈의 개인 공부 범위와 세 확인 질문](README.md#weekly-study)을 오프라인 모임 전까지 준비한다. 모임은 그 주 학습을 마무리하고 남은 보충을 정하는 자리다. 개념·공식 지정 절·복습과 준비된 실습의 정상→변경→복구는 개인 공부에서 시도한다. 모임 전 완성 답안·발표 자료를 요구하지 않으며 막힌 질문과 본인 근거를 가져오게 한다. 진단 원인을 가리는 과제는 정상 기준과 도구까지만 준비한다.

오프라인은 한 번의 모임에서 **설명 → 새 조건 → 본인 실습/분석 확인 → 보충 결정**으로 진행한다. 아래 60분은 시간 배분 예시이며 모임 길이나 추가 회차를 확정하는 표가 아니다.

| 시간 예시 | 진행자가 확인할 것 |
| --- | --- |
| 0~10분 | 개인 공부에서 막힌 질문과 2~4학습 단위 전 개념 하나를 골라 근거로 설명 |
| 10~25분 | 학습 홈의 중심 질문 → 조건 변경. 소그룹에서 설명자/확인자 교대 |
| 25~50분 | A ending 하나 변경→분기/서버 로그 비교→원복, B 같은 HTTP 경로의 수동/자동 정상·중지·복구. 이미 수행했다면 근거를 보고 다른 한 조건의 판단·변경·복구 확인 |
| 50~60분 | 정상 복구·받은 도움·미완료 구분, 개인 학습 노트에 필요한 보충과 다음 질문 연결 |

개인 학습 시간을 고정된 2~3시간으로 제한하지 않는다. 필수 범위를 먼저 공부하고 실제 막힘에 따라 시간을 배분한다. 주차를 미리 분할하거나 필수 기준을 낮추지 않으며, 개인 공부 후에도 해결되지 않는 항목만 보충한다. C04/C08/C12/C16은 해당 주 기존 설명·실습을 대체하고 점검을 별도로 더하지 않는다. 한 사람의 답·팀 합의·파일 제출은 개인 이해/직접 수행의 증거가 아니다.

## 설명을 돕는 짧은 지도

먼저 ‘프로그램이 읽는 조각’과 ‘LF로 정한 메시지’를 종이에 구별한다. 이후 read_line의 누적·LF·EOF·시간제한 분기를 차례로 찾는다. 새로운 문법은 [코드 읽기 지도](LINUX.md#code-reading)에서 필요한 부분만 설명한다. HTTP 클라이언트를 직접 구현하거나 TCP 스택 전체를 강의하지 않는다.

curl 404 종료0과 자동 종료1은 판정 정책이 다르다. 상태·본문·서버 로그를 먼저 맞춘다. timeout이 처리 실패의 증거라는 답에는 수신 후 응답만 늦은 가공 사례를 제시한다. 한 사람이 답한 뒤 다른 사람은 새 조건을 짧게 설명한다. 발표·팀 기록·개인 마무리 고정 양식을 추가하지 않는다.

## 완료와 다음 연결

코드의 경계·부분 수신·EOF·시간제한 위치, A의 직접 변경/원복, B의 동일 입력·수동/자동 대조·복구와 멱등성/재시도 상한 설명을 확인한다. 시연·제공 분석·독립 설명·직접 수행을 나눈다. O05의 기록과 진단 근거를 16주차 동일 서비스로 이어 가되 앞 주의 실제 cloud/O01\~O04 보충을 이번 루프백으로 대체하지 않는다. [분리 해설](ANSWERS.md)·[공식 읽기](SOURCES.md)를 사용한다.
