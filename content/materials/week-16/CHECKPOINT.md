# C16 · 공통 과정의 근거와 남은 보충 찾기

요약: 통신 설명·학부 추론·작은 코드·독립 진단·O01부터 O05까지 운영·필수 수행의 기존 근거를 연결한다. 새 시험지나 기록을 늘리지 않고 막힌 항목만 새 조건으로 확인한다. 미완료가 있으면 범위를 밝히고 부분 완료로 남긴다.

## 기존 근거부터 찾는다

C16은 16주차의 종합 확인이다. 아래는 근거를 찾는 지도이며 점수를 합산하는 시험이 아니다. 개인 파일·앞선 설명/실습 결과를 재사용하고 같은 내용을 다시 입력하지 않는다. 실제 설명·수행을 본 뒤 항목별로 **독립 확인 / 도움 후 보충 필요 / 미확인**을 구분한다. 팀원의 답이나 해설 열람으로 개인의 필수 항목을 상쇄하지 않는다.

## 학부 원리로 돌아갈 지도

- [8주 신뢰적 전송·IPv6](../week-08/README.md): stop-and-wait/GBN/SR의 ACK·재전송 범위를 모형 조건으로 설명한다. ARP와 NDP도 구별한다.
- [9주 링크·VLAN·STP·LACP](../week-09/README.md): 오류 검출과 인증, VLAN과 서브넷, STP 차단과 LACP 멤버를 구별한다. 준비된 구성의 본인 전환/복구는 직접 수행 근거가 필요하다.
- [10주 라우팅](../week-10/README.md): 작은 LS/DV 계산·경로 비용·AS/BGP 정책을 설명하고 OSPF 이웃·경로 전환/복구의 본인 관찰을 찾는다.
- [12주 무선·망·VPN](../week-12/README.md): CSMA/CD와 CSMA/CA·무선 상태·경로/암호화/정책의 경계를 제공 분석으로 설명한다. 제공 분석이 필수인 항목과 실제 구성은 구분한다.
- [14주 계산·혼잡·분산](../week-14/README.md): `L/R`, 전파/처리/큐잉 합, 단순 병목, `BDP=대역폭×RTT`, 이상화한 `W/RTT`의 단위·제외 조건을 설명한다. 실제 처리량 보장으로 읽지 않는다.

앞 풀이가 충분하면 전부 다시 풀지 않는다. 새 조건 예시는 [복습 Q4·Q5](REVIEW.md)이며 독립 설명 전에 해설을 가린다. 신뢰 전송·라우팅·무선 전체를 소켓 코드로 구현하는 것은 요구하지 않는다.

환경이 막히면 무엇을 못 했는지와 필요한 허가 환경·정상→변경→복구·다음 확인 행동을 기존 기록에 남긴다. 시뮬레이터에서 직접 바꾸고 복구했다면 그 환경의 수행으로 인정하되 실제 클라우드 변경 경험과 구별한다. 필수 직접 수행이 빠졌다면 전체 완료로 표시하지 않는다.

## 이후 학습을 고른다

개념이 막히면 연결된 교재의 필요한 절로 돌아가고, 직접 수행이 빠졌다면 먼저 그 환경을 준비한다. 공통 과정의 일부만 확인했다면 그 범위를 말한다. 후속 SRE·플랫폼·클라우드 학습은 부분/복합 장애·부하·용량/신뢰성 설계로 깊이를 넓히는 선택 경로다. 이 자료의 완료가 자격증 합격이나 모든 기업 면접 준비 완료를 뜻하지 않는다.
