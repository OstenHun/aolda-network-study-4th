# 3주차 실행 키트 — 다음 전달 상대 찾기

요약: 승인된 Linux VM에서 경로·이웃을 읽고 짧은 ping과 제한된 ARP/ICMP 관찰을 한다. 실행이 막히면 가상 패킷 예제를 분석하고 직접 수행은 미완료로 남긴다.

## 시작 순서

1. [Linux 절차](LINUX.md)의 허용 대상·NIC·도구·권한을 확인한다. 기존 아올다 Linux VM 한 대를 사용한다.
2. [개인 기록지](PERSONAL_RECORD.md)를 준비한다. 예상은 생각하거나 짧게 말하고 자세한 메모는 선택한다. 실제 명령·출력·패킷은 기록지나 별도 파일에 보관한다. 이름·비밀번호·토큰·공개하면 안 되는 주소는 공유본에 넣지 않는다.
3. 필수 실험 A의 조회와 필수 실험 B의 제한된 관찰을 진행한다. 둘 다 실행 전 예상, 실제 근거, 수정한 설명을 남긴다.
4. 실행할 수 없으면 [설명용 가상 패킷 예제](sample-trace.txt)의 번호를 근거로 분석한다. 이는 실제 VM 캡처나 개인 실험 완료 증거가 아니다.

## 완료 구분

본인 직접 조회와 ping·캡처, 제공 자료 분석, 짝 시연 관찰을 별도 표시한다. `ip route get`은 로컬 경로 선택, `ip neigh`는 그때의 이웃 상태, ping은 ICMP 응답 여부를 보여준다. 어느 하나만으로 상대 서비스나 전체 경로의 정상 작동을 단정하지 않는다.
