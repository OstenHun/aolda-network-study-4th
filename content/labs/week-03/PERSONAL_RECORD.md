# 3주차 개인 기록 — 다음 전달 상대

요약: 내 예상과 실제 조회·패킷 근거를 기록하고, 제공된 가상 패킷 예제 분석을 별도로 표시한다. 공개본에는 이름·인증 정보·민감한 주소를 넣지 않는다.

예상은 생각하거나 짧게 말해도 된다. 아래 상세 메모는 필요한 만큼 쓰고, 실제 명령·출력·패킷을 별도 파일로 보관했다면 그 위치를 적는다. 팀 활동지에 원본 출력을 다시 옮기지 않는다. 이 페이지는 실습 근거를 정리할 때 참고하는 메모다. 별도 파일이나 자유로운 노트를 사용해도 되며 모든 칸을 채울 필요는 없다.

## 출처와 환경

- 작성 날짜 / 팀: 미작성 / 미작성. 공개 공유본에는 개인 이름을 쓰지 않는다.
- 근거 종류: [ ] 내 Linux 직접 실행 [ ] 짝 시연 관찰 [ ] [가상 패킷 예제](sample-trace.txt) 분석 [ ] 설명 모형
- VM 접속·승인 목적지·NIC·권한 확인 상태: 미확인. 실제 목적지 원값은 개인 보관하고 공유본에는 필요한 범위만 가린다.
- 캡처 가능 여부 / 직접 실행하지 못한 이유: 미확인

## 실험 A — 주소·경로·이웃 읽기

| 예상 | 실제 명령·출력의 필요한 부분과 출처 | 설명을 바꾼 점 |
| --- | --- | --- |
| 선택 `dev`·`via`·내 IP/MAC·다음 상대·이웃 상태: 미작성 | 미실시 | 미작성 |

- `ip -4 route get`의 목적지·`dev`·`src`·`via` 유무: 미관찰
- `link/ether` 여부와 NIC의 MAC: 미관찰
- ping 전 다음 상대 IPv4·이웃 행/상태 또는 `행 없음`: 미관찰
- 실제 값인지 제공 예제의 A/B 어느 행인지: 미작성

## 실험 B — 제한된 ping·ARP/ICMP 비교

| 예상 | 실제 명령·필터·시간·ping/캡처 근거 | 설명을 바꾼 점 |
| --- | --- | --- |
| ARP 요청/응답·Echo 요청/응답: 미작성 | 미실시 | 미작성 |

- 승인 범위·실제 캡처 NIC·필터 `arp or (icmp and host TARGET)` 확인: 미확인
- 캡처 시작/종료·패킷 수 또는 `0 packets`·번호: 미관찰
- ping 명령·종료 상태·송신/수신 수: 미실시
- ping 뒤 이웃 행/상태, MAC이 누구의 것인지: 미관찰
- 보이지 않은 패킷 또는 실패에서 가능한 가설과 추가 확인 필요 근거: 미작성
- 직접 캡처가 불가능했다면 제공 trace의 사례·행 번호와 알 수 없는 실제 VM 상태: 미작성. 캡처 미실행을 실제 0 packets와 구별하고, 직접 조회·ping은 별도로 확인한다.

## 그림·자기 설명·완료 상태

- 내 PC → SSH 접속 경로와 VM 내부 NIC → 다음 상대 → IP 목적지 그림(확인된 부분만): 미작성
- `IP 목적지`와 `Ethernet 목적 MAC`이 같은 상대를 가리키는 경우/다른 경우를 2분 설명: 미실시
- 1주차 `lo` HTTP 캡처에서 ARP를 요구하지 않는 이유: 미작성
- 짝의 근거 질문 / 내가 수정한 설명: 미작성
- 토론 뒤 `route get`·이웃 행을 도움 없이 다시 읽고 확인한 판단(추가 ping 없이): 미실시
